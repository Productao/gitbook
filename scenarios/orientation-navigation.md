# Scenarios Orientation & Navigation

Scenarios provide a rich environment for workforce planning. This guide will help you navigate the interface, understand the toolbar, and efficiently move between different views and features.

---

## Scenario Interface Overview

When you open a scenario, the interface consists of several key areas:

**Main Content Area**: Displays org chart, directory table, forecast projections, or hub analytics depending on your selected view

**Top Toolbar**: Contains view selector, before/after toggle, and action buttons

**Side Panel (Taskbar)**: Provides quick access to common actions and scenario information

**Change Tracker Panel**: Shows real-time impact of your changes (can be toggled on/off)

## Scenario Toolbar

The toolbar at the top provides essential controls for working with scenarios:

### View Selector

Switch between different ways of viewing your scenario:

**Views available:**
- **Org Chart**: Visual hierarchy showing reporting structure
- **Directory**: Table view for bulk analysis and editing
- **Forecast**: Time-based projections by period
- **Workforce Hub**: Analytics and org health metrics

> **[Screenshot placeholder: View selector dropdown showing Org Chart, Directory, Forecast, Workforce Hub options]**

**Keyboard shortcuts:**
- `3`: Switch to Org Chart
- `5`: Switch to Directory
- Press `/` and type view name for quick switching

### Before/After/Changes Toggle

Control what state you're viewing:

**Show Before**: View the baseline (Main Org) state

**Show After**: View with all scenario changes applied

**Show Changes**: View the delta (what's changing)

> **[Screenshot placeholder: Before/After/Changes toggle buttons with "Show Changes" selected]**

**When to use each:**
- Use "Show After" while making changes (default working mode)
- Use "Show Changes" to review impact and communicate to stakeholders
- Use "Show Before" to reference baseline or understand current state

### Action Buttons

Common actions available in the toolbar:

**Save**: Commit your changes (also `CMD/CTRL + S`)

**Export**: Download scenario data or visuals

**Share**: Configure who can access this scenario

**Submit for Approval**: Send scenario through approval workflow

**Scenario Menu (•••)**: Additional actions like duplicate, delete, rename

> **[Screenshot placeholder: Toolbar action buttons highlighted]**

## Scenario Taskbar (Side Panel)

The taskbar on the side provides quick access to scenario information and actions:

### Scenario Information

**Scenario name and description**: Click to edit

**Tags and symbols**: Visual identifiers for quick organization

**Owner and collaborators**: Who has access to this scenario

**Status**: Draft, In Review, Approved, etc.

> **[Screenshot placeholder: Taskbar showing scenario info section with name, tags, symbols, and status]**

### Quick Actions

Common scenario operations:

**Create Position**: Add a new position to the scenario

**Close Position**: Remove or eliminate an existing position

**Bulk Operations**: Perform actions on multiple positions at once

**Filters**: Show/hide positions based on criteria

**Search**: Find specific people or positions

> **[Screenshot placeholder: Taskbar quick actions section]**

### Change Summary

Real-time overview of your scenario impact:

**Headcount changes**: +additions, -reductions, net change

**Cost impact**: Total dollar change from baseline

**Positions modified**: Count of changed positions

**Click to expand**: Opens full Change Tracker panel

> **[Screenshot placeholder: Change summary widget in taskbar]**

## Navigating Views

### Org Chart View

**Navigation:**
- **Pan**: Click and drag background
- **Zoom**: Scroll wheel or pinch gesture
- **Fit to screen**: Click fit icon in corner
- **Expand/collapse**: Click arrow icons on manager cards
- **Center on position**: Double-click position card

**Finding positions:**
- Use search bar at top
- Filter by department, location, or custom fields
- Click breadcrumbs to jump to specific managers

> **[Screenshot placeholder: Org Chart view with navigation controls highlighted]**

### Directory View

**Navigation:**
- **Scroll**: Scroll vertically through position list
- **Sort**: Click column headers
- **Filter**: Use filter bar above table
- **Column visibility**: Click columns icon to show/hide fields

**Finding positions:**
- Type in search box for name/title search
- Use filters for advanced queries
- Sort by any column to find outliers

> **[Screenshot placeholder: Directory view with filter bar and column controls]**

### Forecast View

**Navigation:**
- **Time period**: Select monthly, quarterly, or yearly
- **Year selection**: Choose which year to display (for monthly/quarterly)
- **Aggregation**: Choose what dimension to view (department, location, etc.)
- **Metric**: Toggle between headcount and cost
- **Expand/collapse**: Click row headers to drill into details

> **[Screenshot placeholder: Forecast view with time period and aggregation controls]**

### Workforce Hub View

**Navigation:**
- **Chart selection**: Choose which analytics chart to view
- **Dimension selection**: Configure X and Y axes for charts
- **Filters**: Apply filters to focus analysis
- **Before/After toggle**: See current vs proposed metrics

**Available charts:**
- Layers & Spans Chart
- Headcount Distribution Chart
- Headcount Heatmap Chart

> **[Screenshot placeholder: Workforce Hub with chart selector and dimension controls]**

## Change Tracker Panel

The Change Tracker panel provides detailed impact analysis:

### Opening/Closing the Panel

**Toggle Change Tracker:**
- Click "Change Tracker" button in toolbar
- Panel slides in from right side
- Click "X" or click button again to close

### What's in the Change Tracker

**Summary section:**
- Net headcount change
- Total cost impact
- Count by change type (additions, reductions, modifications)

**Department breakdown:**
- Headcount change by department
- Cost impact by department
- Drill into specific departments

**Position list:**
- Every changed position
- What changed (before → after)
- Cost impact per change
- Click position to navigate to it

> **[Screenshot placeholder: Change Tracker panel showing summary, department breakdown, and position list]**

## Keyboard Shortcuts

Master these shortcuts to navigate efficiently:

### View Navigation
- `3`: Org Chart view
- `5`: Directory view
- `CMD/CTRL + K`: Quick search/command palette
- `/`: Focus search bar

### Common Actions
- `CMD/CTRL + S`: Save scenario
- `CMD/CTRL + Z`: Undo last action
- `CMD/CTRL + SHIFT + Z`: Redo
- `ESC`: Close panels or dialogs

### Selection and Editing
- `SHIFT + Click`: Select range (in Directory view)
- `CMD/CTRL + Click`: Multi-select individual items
- `Enter`: Open selected position for editing
- `Tab`: Move to next field when editing

### Global Search

**Access:** Click search bar at top or press `/`

**What you can search:**
- Employee names
- Position titles
- Managers
- Departments

**Search tips:**
- Search is instant as you type
- Case-insensitive
- Searches across all fields

### Filters

## Breadcrumbs and Navigation Paths

### Org Chart Breadcrumbs

When navigating deep into the org chart, breadcrumbs show your path:

**Example:** CEO > VP Engineering > Director Platform > Manager Infra

**Use breadcrumbs to:**
- Understand your current location in hierarchy
- Jump back to parent levels
- Share specific org chart locations

At the top of the interface, you'll see:

- Return to scenario list
- Navigate to home
- Understand current context

## Tips for Efficient Navigation

### Use Views for Different Tasks

**Org Chart** → Drag-and-drop reorganizations, visualizing structure

**Directory** → Bulk edits, filtering and analysis, reviewing changes

**Forecast** → Time-based planning, understanding phasing

**Workforce Hub** → Validating org health, analyzing span of control

### Master the Toggle

**Work in "Show After"** → Make changes and see results

**Validate in "Show Changes"** → Review impact before submitting

**Reference "Show Before"** → Understand baseline when needed

### Leverage Keyboard Shortcuts

- `3` to see structure
- `5` to bulk edit
- `CMD/CTRL + K` to search and navigate quickly
- `CMD/CTRL + S` to save frequently

### Keep Change Tracker Open

While working, keep Change Tracker panel open to:
- Monitor impact in real-time
- Catch unintended changes immediately
- Stay aware of cost and headcount targets

## Common Navigation Scenarios

### "I want to find a specific person"

1. Press `/` to open search
2. Type person's name
3. Select from results
4. Opens position card or navigates to them in org chart

### "I want to see all Engineering positions"

1. Switch to Directory view (`5`)
2. Open filters
3. Filter by Department = "Engineering"
4. Review filtered list

### "I want to see the cost impact by department"

1. Open Change Tracker panel
2. Scroll to department breakdown section
3. Review cost impact per department
4. Or switch to Forecast view and select Cost metric

### "I want to navigate up the org chart"

1. In Org Chart view, use breadcrumbs at top
2. Click parent levels to zoom up hierarchy
3. Or click "Fit to Screen" to see full org

### "I want to see when changes take effect"

1. Switch to Forecast view
2. Select quarterly or monthly time aggregation
3. Set aggregation to Department
4. Toggle to "Show Changes" to see impact by period
