# Scenario Exporting

Export your scenario data, visuals, and analytics to share with stakeholders, create presentations, perform external analysis, and document your planning work. Agentnoon provides multiple export formats optimized for different use cases.

---

## Export Options Overview

Scenarios can be exported in several formats:

**Visual Exports:**
- Org Chart as JPEG (screenshot)
- Org Chart as PowerPoint (hierarchical slides)
- Workforce Hub charts as PNG

**Data Exports:**
- CSV (scenario data)
- Excel (formatted scenario data)
- Change summary exports
- Forecast projections
- Before/After comparison data

## Exporting Scenario Org Charts

### JPEG Export

Export a screenshot image of your scenario org chart.

**How to export:**
1. Open your scenario
2. Switch to Org Chart view
3. Toggle to "Show After" (or desired view mode)
4. Frame the view you want to capture
5. Click "Export" button
6. Select "JPEG" format
7. Download image

**Best for:**
- Quick screenshots for emails or Slack
- Informal stakeholder updates
- Documenting specific organizational segments
- Comparing Before and After visually

**Pro tip:** Export both "Show Before" and "Show After" to create side-by-side comparisons in presentations.

> **[Screenshot placeholder: Scenario org chart with Export button and JPEG option]**

### PowerPoint Export

Export your scenario org chart as a structured PowerPoint presentation.

**How to export:**
1. Open your scenario
2. Switch to Org Chart view
3. Select "Show After" to export proposed state
4. Click "Export" button
5. Select "PowerPoint" format
6. Configure export options:
   - Apply filters (export specific departments)
   - Set hierarchy depth (how many layers)
   - Choose layout (vertical, horizontal, compact)
   - Set slide depth (layers per slide)
   - Select card content (titles only or full details)
7. Click "Download"

**What gets exported:**
- Your scenario's "After" state by default
- One slide per manager with direct reports
- Professional formatting
- Customizable layout and detail level

**Best for:**
- Presenting reorganization plans to leadership
- Sharing proposed org structure with stakeholders
- Creating formal approval documentation
- Board presentations

## Exporting Scenario Data

### CSV Export

Export raw scenario data for analysis in Excel, BI tools, or databases.

**How to export:**
1. Open your scenario
2. Switch to Directory view
3. Apply filters if you want a subset (optional)
4. Click "Export" button
5. Select "CSV" format
6. Download CSV file

**What's included:**
- All positions in scenario ("Show After" state)
- All attributes (name, title, department, salary, etc.)
- Change indicators (added, removed, modified)
- Custom attributes
- One row per position

**Best for:**
- Detailed analysis in Excel
- Custom reporting
- Importing into BI tools
- Sharing with analysts

**CSV export respects:**
- Current view mode (Before/After/Changes)
- Applied filters
- Your access permissions

### Excel Export

Export formatted scenario data as Excel spreadsheet.

**How to export:**
1. Open your scenario
2. Optional: Apply filters in Directory view
3. Click "Export" button
4. Select "Excel" format
5. Download Excel file

**Includes:**
- Formatted headers
- Correct data types
- Multiple sheets (may include summary sheet)
- Pre-formatted for analysis

**Best for:**
- Sharing with stakeholders who use Excel
- Creating pivot tables
- Formal reporting
- Quick analysis without formatting work

## Exporting Change Summary

Export a summary of all changes in your scenario:

**How to export:**
1. Open your scenario
2. Open Change Tracker panel
3. Click "Export Changes" button
4. Select format (CSV or Excel)
5. Download file

**What's included:**
- List of all changed positions
- Change type (addition, reduction, modification)
- Before and after values for modified attributes
- Cost impact per change
- Department and location for each change
- Effective dates (if configured)

**Best for:**
- Communicating impact to stakeholders
- Approval documentation
- Audit trails
- Implementation planning

> **[Screenshot placeholder: Change Tracker panel with "Export Changes" button highlighted]**

**Use cases:**
- Send to finance for budget approval
- Share with HR for implementation
- Document approved changes
- Create implementation checklist

## Exporting Forecast Projections

Export time-based projections from your scenario:

**How to export:**
1. Open your scenario
2. Switch to Forecast view
3. Configure:
   - Time period (monthly, quarterly, yearly)
   - Aggregation dimension (department, location, etc.)
   - Metric (headcount or cost)
   - Year selection (for monthly/quarterly)
4. Toggle to desired view mode (Before/After/Changes)
5. Click "Export" button
6. Download file

**What's included:**
- Rows for each department/location/etc.
- Columns for each time period
- Headcount or cost values
- Phasing based on effective dates

**Export options:**
- **Show Before**: Export baseline projections
- **Show After**: Export scenario projections
- **Show Changes**: Export delta (+/-) by period

**Best for:**
- Budget planning presentations
- Quarterly headcount forecasts
- Showing phased impact of changes
- Financial analysis

## Exporting Workforce Hub Analytics

Export charts and data from Scenario Workforce Hub:

### Chart Image Exports

**How to export:**
1. Open your scenario
2. Switch to Workforce Hub view
3. Select and configure chart (Layers & Spans, Distribution, Heatmap)
4. Toggle to "Show After" to see scenario impact
5. Click "Export" button
6. Select "PNG" format
7. Download image

**Best for:**
- Presentations showing org health impact
- Documenting span of control improvements
- Sharing analytics insights
- Before/After metric comparisons

**Pro tip:** Export same chart in "Show Before" and "Show After" modes to show scenario impact on org health.

### Chart Data Exports

**How to export:**
1. Open scenario > Workforce Hub
2. Configure chart
3. Click "Export" button
4. Select "CSV" or "Excel" format
5. Download data file

**What's included:**
- Underlying analytics data
- Aggregated metrics (span of control, headcount by layer, etc.)
- Dimension labels

**Best for:**
- Custom analysis
- Creating custom visualizations
- Combining with other data sources

## Exporting Scenario Comparisons

When comparing multiple scenarios, you can export the comparison:

**How to export:**
1. Navigate to Scenario Comparisons
2. Select scenarios to compare
3. Configure comparison view (headcount, cost, etc.)
4. Click "Export Comparison" button
5. Select format (CSV, Excel, or PowerPoint)
6. Download file

**What's included:**
- Side-by-side data for each scenario
- Headcount changes per scenario
- Cost impact per scenario
- Department-by-department breakdown
- Summary comparison metrics

**Best for:**
- Presenting multiple options to leadership
- Evaluating trade-offs between approaches
- Decision-making documentation
- Approval workflows with alternatives

## Export Strategies for Different Use Cases

### For Approval Submissions

**Export package:**
1. Change summary (Excel)
2. Org chart PowerPoint ("Show After")
3. Cost impact by department (Forecast export)
4. Workforce Hub analytics showing org health

**Purpose:** Provide complete documentation for approvers

### For Stakeholder Communication

**Export package:**
1. Org chart JPEG showing affected area
2. Change summary filtered to relevant department
3. Forecast showing timing of changes

**Purpose:** Communicate specific impacts to department leaders

### For Implementation Planning

**Export package:**
1. Complete change list (CSV)
2. Positions by effective date (sorted)
3. New hire requisitions (filtered export)
4. Position closures (filtered export)

### For Financial Analysis

**Export package:**
1. Forecast export with cost projections by quarter
2. Change summary with cost impact per change
3. Before/After headcount by department
4. Excel export of all positions with salaries

**Purpose:** Enable detailed budget planning and approval

## Export Best Practices

### Export Multiple View Modes

**Always export:**
- "Show After" for proposed state
- "Show Changes" for impact communication
- "Show Before" for baseline reference (when needed)

**Why:** Different audiences need different perspectives

### Use Filters to Focus Exports

**Before exporting:**
- Filter to relevant department or segment
- Exclude unrelated positions
- Focus on what stakeholders need

**Benefits:**
- Smaller file sizes
- Clearer communication
- Protect sensitive data outside scope

### Add Context with Scenario Name

**Best practice:** Ensure scenario name is descriptive before exporting

**Good scenario names for exports:**
- "Q1 2026 Sales Reorg - West Coast"
- "Annual Hiring Plan - Engineering FY2027"
- "Budget Cut Scenario - 10% Reduction"

**Why:** Exported files often include scenario name, helping recipients understand context

### Export at Key Milestones

**When to export:**
- Before submitting for approval (create documentation)
- After approval (archive approved state)
- At major revisions (track evolution)
- Before major changes (backup)

**Purpose:** Create audit trail and enable rollback if needed

### Combine Exports for Complete Story

**Don't just export data:**
- Include visuals (org charts, Hub analytics)
- Include context (change summaries, justifications)
- Include projections (forecast data)

**Complete package tells better story** than raw data alone

## Export Permissions and Access Control

Scenario export permissions depend on your role and scenario access:

**Scenario Owner:**
- Can export all scenario data
- Can export in all formats
- Can export changes and analytics

**Scenario Collaborator (Edit):**
- Can export scenario data
- Can export visuals
- Can export changes

**Scenario Viewer:**
- Can export visuals (org chart, Hub)
- May have data export restrictions
- Cannot export change details (depending on settings)

**Access group restrictions apply:**
- Exports respect your data access boundaries
- You can only export positions you have access to
- Sensitive attributes may be hidden based on permissions

## Troubleshooting Scenario Exports

**Export button is grayed out:**
- Ensure you have at least view access to the scenario
- Check that you're in a supported view
- Contact scenario owner if you need export access

**Exported data doesn't match what I see:**
- Check which view mode is active (Before/After/Changes)
- Verify filters are applied as expected
- Ensure you're exporting from correct view (Directory, Forecast, etc.)

**Change summary export is empty:**
- Scenario may have no changes yet
- Try switching to "Show Changes" mode first
- Verify Change Tracker shows changes

**Effective dates aren't showing in export:**
- Effective dates may not appear in all export formats
- Try exporting from Forecast view for time-phased data
- Change summary export includes effective dates

**Can't export scenario comparison:**
- Ensure you've selected multiple scenarios to compare
- Check that comparison view is active
- Verify you have access to all scenarios being compared
