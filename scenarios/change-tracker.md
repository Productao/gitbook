# Change Tracker

### Overview

This guide explains how to use the **OPEX panel and changelog tracker** in Agentnoon to monitor workforce changes, track cost savings, and compare budget allocations in a scenario.

### Accessing the Changelog Tracker

1. Click the **👀 button** in the **top right corner** to open the **changelog tracker**.
2. The tracker categorizes changes into different **interactions**:
   * **Additions** (new hires).
   * **Reductions** (layoffs or exits).
   * **Data Changes** (e.g., new position title vs old position title)
3. **View both cost and count impact** for all additions, reductions, and data changes in the changelog.
4.  **Switch between salary and custom formulas** to evaluate changes using your preferred financial metric.<br>

### Viewing Position Changes

1. Click on any position to see **detailed modifications**, including:
   * **Previous employee name** → **New employee name** (if reassigned).
   * **Previous job title** → **New job title**.
2. Example:
   * If an **Account Manager** position is marked as a **reduction**, the tracker logs:
     * The **original position details**.
     * The **status change** (e.g., marked as a layoff).
     * The **associated cost savings**.

### Tracking Cost Savings & Budget Usage

1. The **bottom of the changelog panel** shows **aggregated cost savings** based on reductions.
2. Each **position modification** also displays its **individual financial impact**.
3. If a **budget was assigned at the start of a scenario**, the panel shows **remaining budget vs. spending**.

By using the **OPEX panel and changelog tracker**, you can efficiently **monitor headcount adjustments, assess financial impacts, and manage scenario budgets** in Agentnoon.
