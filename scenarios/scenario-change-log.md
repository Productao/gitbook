# Scenario Change Log

### Overview

This guide explains how to **export scenario change logs** as a **CSV file** in Agentnoon, allowing you to track modifications and analyze changes outside the platform.

#### 1. Accessing the Export Option

* While inside a **scenario**, navigate to the **vertical toolbar**.
* Click the **Download** button.
* Select **Comparison** to export the data.

<figure><img src="../.gitbook/assets/Screenshot 2025-03-06 at 10.59.43 AM.png" alt="" width="563"><figcaption></figcaption></figure>

#### 2. What’s Included in the Export?

The exported CSV file contains:

* **Position Changes** (e.g., title updates, manager reassignments).
* **Headcount Adjustments** (new hires, reductions, or exits).
* **Cost Changes** (salary updates, budget impacts).
* **Other Modifications** made within the scenario.
