# Scenario Management

As you create more scenarios, keeping them organized becomes essential. This section covers tools and best practices for managing your growing library of workforce planning scenarios.

## Overview

Scenario management includes:

1. **Basic actions** - Create, open, rename, duplicate, and delete scenarios
2. **Tagging** - Organize scenarios by department, quarter, or purpose
3. **Visual symbols** - Understand change indicators on position cards
4. **Organization** - Name scenarios clearly, archive old plans, and maintain a clean workspace

Good scenario management helps you:
- Find the right scenario quickly
- Track different versions of plans
- Keep stakeholders aligned on which scenario is current
- Maintain historical records of planning decisions
- Reduce clutter and confusion

### Understanding Scenario Symbols

Visual indicators on position cards show what changed in the scenario:
- ➕ Green icons for newly added positions
- ❌ Red icons for RIF/closed positions
- 🚪 Orange icons for exits (terminations)
- ✏️ Blue icons for edited positions
- 🔀 Purple arrows for moved positions

## Common Workflows

### Finding a Scenario Quickly

**By name:**
1. Go to homepage
2. Use search bar
3. Type scenario name
4. Click to open

**By tag:**
1. Go to scenario list
2. Click tag filter
3. Select department/quarter
4. Browse filtered results

---

### Creating Scenario Versions

**Scenario:** Test 3 different reorganization approaches

**Steps:**
1. Create "Reorg - Option A" (first approach)
2. Duplicate to "Reorg - Option B" (alternative)
3. Duplicate to "Reorg - Option C" (third option)
4. Model different structures in each
5. Use tagging to group them (tag: "Q2 Reorg")
6. Compare to choose best option

---

### Cleaning Up Old Scenarios

**Quarterly cleanup:**
1. Review scenario list
2. Archive implemented scenarios (preserve history)
3. Delete test scenarios no longer needed
4. Update tags for current quarter
5. Rename scenarios with inconsistent names
6. Export change logs for record-keeping

## Exporting Scenario Data

### Export Change Log (CSV)

**What it includes:**
- All position changes (adds, closes, modifications)
- Headcount adjustments
- Cost changes
- Before and after values

**How to export:**
1. Open scenario
2. Click **Export** or **Download** in toolbar
3. Select **Comparison** or **Change Log**
4. Choose **CSV** format
5. Click **Export**
6. File downloads

**When to use:**
- Offline analysis in Excel
- Creating detailed reports
- Archiving scenario decisions
- Sharing with finance team

**Learn more:** [Exporting Scenario Data](../scenarios/exporting.md)

---

### Export Org Chart (PDF)

**What it includes:**
- Visual org chart
- Position details
- Can include symbols/changes

**How to export:**
1. Open scenario
2. Click **Export** button
3. Select **Org Chart**
4. Choose **PDF** format
5. Select options (show symbols, include Change Tracker, etc.)
6. Click **Export**

**When to use:**
- Presentations
- Printed handouts
- Board meetings
- External stakeholders

## Best Practices

1. **Name scenarios clearly from the start** - Don't leave as "Untitled"
2. **Use tags consistently** - Establish tag naming conventions
3. **Duplicate before major changes** - Create v2 instead of destroying v1
4. **Archive implemented scenarios** - Don't delete historical records
5. **Export change logs regularly** - Backup your work
6. **Check symbols before sharing** - Ensure they accurately reflect changes
7. **Delete only test scenarios** - Archive everything else
8. **Use versioning for alternatives** - Compare multiple approaches

---

## Troubleshooting

**Problem:** Can't find a specific scenario.
- **Solution:** Use search bar or filter by tags. Check if scenario was archived.

**Problem:** Scenario list is too cluttered.
- **Solution:** Archive old scenarios, use tags to organize, delete unnecessary test scenarios.

**Problem:** Can't remember which scenario version is latest.
- **Solution:** Use consistent naming (v1, v2, v3) or date stamps (2026-02-15).

**Problem:** Lost track of what changed in a scenario.
- **Solution:** Open scenario and review Change Tracker or export change log for detailed breakdown.
