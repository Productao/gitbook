# Scenario Comparison Exporting

Export side-by-side comparison data and visuals to present alternatives and document decisions.

## Export Formats

**Excel** — Multi-sheet file with: a Summary sheet (scenario names, net headcount/cost per scenario, additions/reductions/modifications count), a Department Breakdown sheet (headcount and cost by department per scenario), and a Change Detail sheet (all position changes per scenario with before/after values). Best for finance teams and detailed analysis.

**CSV** — Single file with all comparison data, one row per position/metric, columns for each compared scenario. Best for BI tools and custom analysis.

**PowerPoint** — Side-by-side org charts with a summary slide. Configure hierarchy depth, slide depth, and card content. Best for executive and board presentations.

## How to Export

1. Navigate to Scenario Comparisons (homepage > select 2–4 scenarios > Compare, or inside a scenario > Compare in toolbar)
2. Configure the comparison view (dimension, filter, metric)
3. Click **Export Comparison**
4. Select format (Excel, CSV, or PowerPoint) and configure options
5. Download

## What to Compare and Export

| Comparison type | Use to decide |
|----------------|---------------|
| Cost | Which option fits the budget |
| Headcount | Which option aligns to growth/reduction targets |
| Org health metrics | Which structure improves SOC, layers, manager-to-IC ratio |
| Timing/effective dates | Which option phases implementation more favorably |

## Best Practices

- **Export before the decision, not after** — capture the state at the decision point
- **Filter before exporting** — focus stakeholders on the relevant org segment
- **Name scenarios clearly** — "Scenario A vs Scenario B" is confusing; use descriptive names
- **Add narrative** — attach a summary with recommendation and pros/cons; data alone doesn't tell the full story
- **Archive the export** — save with decision notes for future audit trail

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Export Comparison button missing | Ensure multiple scenarios are selected in comparison view |
| Scenarios missing from comparison | Verify you have access to all selected scenarios |
| Comparison data looks wrong | Confirm "Show Changes" mode is active and scenarios are saved |
| Export file is very large | Apply department filters; export fewer scenarios; use CSV instead of Excel |
| PowerPoint won't open | Try Google Slides; re-download if the file is corrupted |
