# Scenario Comparison Exporting

When comparing multiple scenarios side-by-side, you can export the comparison data and visuals to share with stakeholders, document decision-making, and present alternatives to leadership.

---

## Overview

Scenario comparison exports allow you to:

- Share multiple options with decision-makers
- Document trade-offs between approaches
- Present alternatives in approval workflows
- Archive comparison analysis for future reference
- Create decision documentation

> **[Screenshot placeholder: Scenario comparison view with Export button highlighted]**

---

## Accessing Comparison Exports

**Prerequisites:**
1. You must have at least two scenarios created
2. You must have access to all scenarios you want to compare
3. Navigate to Scenario Comparisons feature

**To access:**
1. From scenario list, click "Compare Scenarios" button
2. Select 2 or more scenarios to compare
3. Configure comparison view (headcount, cost, etc.)
4. Click "Export Comparison" button

---

## Export Formats

### Excel Comparison Export

Export side-by-side scenario data as formatted Excel file.

**How to export:**
1. Configure scenario comparison view
2. Select scenarios to compare (2-5 scenarios)
3. Click "Export Comparison"
4. Select "Excel" format
5. Download file

**What's included:**

**Summary Sheet:**
- Scenario names and descriptions
- Net headcount change per scenario
- Total cost impact per scenario
- Number of additions/reductions/modifications per scenario
- Key metrics comparison

**Department Breakdown Sheet:**
- Headcount changes by department for each scenario
- Cost impact by department for each scenario
- Side-by-side comparison columns

**Change Detail Sheet:**
- All position changes for each scenario
- Change type indicators
- Before and after values
- Department and attributes

> **[Screenshot placeholder: Excel file with multiple sheets showing scenario comparison data]**

**Best for:**
- Detailed analysis by stakeholders
- Creating pivot tables for custom views
- Sharing with finance teams
- Approval documentation

### CSV Comparison Export

Export raw comparison data as CSV for analysis.

**How to export:**
1. Configure comparison view
2. Select scenarios
3. Click "Export Comparison"
4. Select "CSV" format
5. Download file

**What's included:**
- One CSV file with all comparison data
- Each row represents a position or aggregate metric
- Columns for each scenario being compared
- Change indicators and deltas

**Best for:**
- Importing into BI tools
- Custom analysis in data tools
- Integration with other systems
- Maximum flexibility

### PowerPoint Comparison Export

Export side-by-side org chart visuals as PowerPoint.

**How to export:**
1. Select scenarios to compare
2. Configure comparison view
3. Click "Export Comparison"
4. Select "PowerPoint" format
5. Configure options:
   - Layout (side-by-side or sequential)
   - Hierarchy depth
   - Slide depth (layers per slide)
   - Card content detail
6. Download presentation

**What's included:**
- Title slide with scenario names
- Side-by-side org charts (or sequential slides per scenario)
- Summary slide with key metrics
- Professional formatting

> **[Screenshot placeholder: PowerPoint export with two org charts side-by-side]**

**Best for:**
- Executive presentations
- Board meetings
- Approval workflows with alternatives
- Visual comparison for decision-making

## Comparison Metrics to Export

### Headcount Comparison

**Metrics exported:**
- Net headcount change per scenario
- Additions count per scenario
- Reductions count per scenario
- Modifications count per scenario
- Headcount by department per scenario

**Use to compare:**
- Which scenario adds more positions
- Which scenario reduces more positions
- Departmental impact differences

### Cost Comparison

**Metrics exported:**
- Total cost impact per scenario
- Cost by department per scenario
- Cost increases vs decreases per scenario
- Average salary impact per scenario

**Use to compare:**
- Which scenario is most cost-effective
- Budget impact differences
- ROI of different approaches

### Organizational Health Comparison

**Metrics exported:**
- Span of control metrics per scenario
- Layers metrics per scenario
- Manager-to-IC ratio per scenario
- Open positions per scenario

**Use to compare:**
- Which scenario creates healthier org structure
- Which scenario reduces layers
- Which scenario improves span of control

### Timing Comparison

**Metrics exported:**
- Changes by effective date per scenario
- Phased rollout differences
- Implementation timeline per scenario
- Quarterly headcount projections per scenario

**Use to compare:**
- Which scenario can be implemented faster
- Budget impact timing differences
- Hiring plan phasing differences

## Export Configuration Options

### Selecting Scenarios to Compare

**How many scenarios:**
- Minimum: 2 scenarios
- Maximum: 5 scenarios (recommended)
- More scenarios = harder to compare

**Which scenarios to include:**
- Select scenarios with similar scope for fair comparison
- Include a "baseline" scenario if available
- Choose scenarios representing distinct alternatives

### Filtering Comparison Data

**Apply filters before exporting:**
- Department filter (compare specific segments)
- Location filter
- Change type filter (additions only, reductions only, etc.)

**Benefits:**
- Focus stakeholders on relevant comparisons
- Reduce data overwhelming
- Highlight specific trade-offs

### Choosing Comparison Dimensions

**Compare by:**
- Department
- Location
- Job Level
- Employee Type
- Time period (quarterly, yearly)

**Best practice:** Choose dimension most relevant to decision criteria

## Use Cases for Comparison Exports

### Presenting Alternatives to Leadership

**Scenario:**
You've created 3 reorganization scenarios with different approaches.

**Export strategy:**
1. Export PowerPoint comparison (side-by-side org charts)
2. Export Excel comparison with cost impact
3. Include summary slide highlighting pros/cons

**Outcome:** Leadership can visually compare structures and see cost trade-offs.

### Budget Approval with Options

**Scenario:**
Finance asks to see multiple budget scenarios.

**Export strategy:**
1. Create scenarios: Aggressive hiring, Moderate hiring, Conservative hiring
2. Export Excel comparison with quarterly cost projections
3. Include departmental breakdown

**Outcome:** Finance approves budget based on clear trade-offs.

### Evaluating Reorganization Timing

**Scenario:**
Comparing phased vs immediate reorganization.

**Export strategy:**
1. Create two scenarios with different effective dates
2. Export comparison with timing metrics
3. Show quarterly impact differences

**Outcome:** Choose approach based on business capacity and budget phasing.

### Documenting Decision Rationale

**Scenario:**
Need to document why Scenario B was chosen over Scenario A.

**Export strategy:**
1. Export comparison at time of decision
2. Include metrics that drove decision
3. Archive for future reference

**Outcome:** Clear audit trail of decision-making process.

## Best Practices

### Keep Scenarios Comparable

**Ensure scenarios:**
- Start from same baseline (same Main Org snapshot)
- Address same business problem
- Have similar scope (don't compare full reorg vs minor adjustment)

**Why:** Fair comparison requires similar starting points

### Export Before Final Decision

**Timing:**
- Export comparison after all scenarios are finalized
- Before decision is made (not after)
- At key review milestones

**Why:** Capture state at decision point, not retrospectively

### Include Context in Export

**Add context:**
- Scenario names should be descriptive
- Include scenario descriptions
- Add notes about key assumptions
- Document decision criteria

**Why:** Future readers need context to understand comparison

### Combine with Narrative

**Don't just export data:**
- Add executive summary slide/sheet
- Include recommendation with rationale
- Highlight key trade-offs
- Note pros and cons of each option

**Why:** Data alone doesn't tell complete story

### Archive Comparison Exports

**Save exports when:**
- Major decisions are made
- Alternatives were presented to leadership
- Approval workflows completed

**Why:** Create audit trail and historical reference

## Comparison Export Workflow Example

### Step 1: Create Scenarios

Create 3 scenarios:
- **Scenario A:** Engineering reorg with 4 new teams
- **Scenario B:** Engineering reorg with 3 new teams
- **Scenario C:** Engineering reorg with 2 new teams

### Step 2: Finalize Scenarios

Review each scenario for:
- Complete position changes
- Cost accuracy
- Effective dates set
- Org health validation

### Step 3: Configure Comparison

1. Navigate to Scenario Comparisons
2. Select all 3 scenarios
3. Set comparison dimension to "Department"
4. Apply filter to "Engineering" only

### Step 4: Export Comparison

1. Click "Export Comparison"
2. Select "PowerPoint" for exec presentation
3. Configure side-by-side layout
4. Set hierarchy depth to 3 layers
5. Download presentation

### Step 5: Export Data

1. Also export Excel comparison
2. Include cost and headcount metrics
3. Download for detailed analysis

### Step 6: Create Summary

1. Open PowerPoint export
2. Add title slide with decision criteria
3. Add summary slide with recommendation
4. Add notes with pros/cons for each option

### Step 7: Present and Decide

1. Present to leadership
2. Discuss trade-offs
3. Make decision
4. Archive comparison export with decision notes

## Troubleshooting

**Can't find Export Comparison button:**
- Ensure you've selected multiple scenarios to compare
- Check that comparison view is active
- Verify scenarios are loaded

**Some scenarios missing from comparison:**
- Check you have access to all selected scenarios
- Verify scenarios are not archived or deleted
- Ensure scenarios share same Main Org baseline

**Comparison data looks wrong:**
- Verify "Show Changes" mode is active
- Check that filters are applied correctly
- Ensure scenarios have been saved recently

**Export file is very large:**
- Try applying filters to reduce scope
- Export fewer scenarios at once
- Use CSV instead of Excel for large datasets

**Can't open exported PowerPoint:**
- Ensure you have PowerPoint or compatible software
- Try opening in Google Slides
- Check file wasn't corrupted during download
