# Scenario Tags

Tags are labels you attach to scenarios to group related plans together. This guide covers creating, applying, and filtering scenarios by tags to keep your workspace organized.

---

## What Are Tags?

**Tags** are organizational labels that help you categorize and filter scenarios.

**Why use tags:**
- Group scenarios by department, quarter, or project
- Quickly filter scenario list to find what you need
- Keep related scenarios together
- Make collaboration easier (stakeholders find relevant scenarios)
- Maintain organization as scenario count grows

## Creating Tags

### How to Create

**Method 1: Create while applying**
1. Go to scenario list
2. Click **⋮** menu on any scenario
3. Select **Change Tag** or **Add Tag**
4. Type new tag name
5. Press **Enter**
6. Tag created and applied to scenario

**Method 2: Create from tag management** (if available)
1. Go to Settings or Tag Management
2. Click **Create New Tag**
3. Enter tag name
4. Save
5. Tag available for use

### Tag Naming Best Practices

**Good tag names:**
- Short and clear
- Consistent format across scenarios
- Avoid special characters
- Use proper capitalization for readability

**Examples:**
- ✅ "Q2 2026"
- ✅ "Engineering"
- ✅ "Budget Cuts"

**Avoid:**
- ❌ "q2 2026" (inconsistent capitalization)
- ❌ "Engineering-Dept-2026" (too specific, use multiple tags)
- ❌ "scenarios for the engineering reorg project" (too long)

## Applying Tags to Scenarios

### How to Add Tag

1. Find scenario in list
2. Click **⋮** menu
3. Select **Change Tag** or **Add Tag**
4. Choose existing tag from dropdown OR create new
5. Tag applied

**Visual indicator:**
- Scenarios show tag label
- Usually appears as colored badge or label
- Can see at a glance which tag is applied

### Multiple Tags

**Support varies by system:**
- Some systems support single tag per scenario
- Others allow multiple tags per scenario
- Check with your admin for your setup

**Example with multiple tags:**
- Scenario: "Q2 Hiring Plan"
- Tags: "Engineering", "Q2 2026", "Hiring"

## Filtering by Tags

### How to Filter

**From homepage/scenario list:**
1. Click **Filter** or tag dropdown
2. Select tag
3. Only scenarios with that tag appear
4. Clear filter to see all scenarios again

**Multiple filters** (if supported):
1. Select first tag
2. Add additional filters
3. Only scenarios matching all filters appear

### When to Use Filtering

**Find all scenarios for a department:**
1. Filter by "Engineering"
2. See all engineering-related scenarios
3. Review, compare, or share with department

**See all scenarios for a quarter:**
1. Filter by "Q2 2026"
2. View all Q2 planning scenarios
3. Prepare for quarterly review meeting

**Focus on specific project:**
1. Filter by "AI Initiative"
2. See all related scenarios
3. Track progress across planning efforts

## Removing Tags

### How to Remove

1. Click **⋮** menu on scenario
2. Select **Change Tag** or **Edit Tags**
3. Select "No Tag" or clear selection
4. Tag removed from scenario

**When to remove:**
- Tag no longer applies
- Scenario moved to different category
- Cleaning up old tags
- Preparing to apply new tag

---

## Tag Management

### Renaming Tags

**System-level rename** (if supported):
1. Go to tag management settings
2. Find tag to rename
3. Edit name
4. Save
5. All scenarios with old tag now have new tag

**Manual rename:**
1. Remove old tag from each scenario
2. Apply new tag to each scenario

**Tip:** Use system-level rename if available to avoid missing scenarios.

---

### Deleting Tags

**How to delete:**
1. Go to tag management settings
2. Find tag to delete
3. Click delete or remove
4. Confirm deletion
5. Tag removed from all scenarios

**When to delete:**
- Tag no longer relevant (old quarter)
- Duplicate tags exist
- Consolidating tag structure
- Cleanup after project completion

**Warning:** Deleting tag removes it from all scenarios. Make sure this is intended.

## Tag Strategies

### Strategy 1: Department + Quarter

**Setup:**
- Tag by department: "Engineering", "Sales", "Marketing"
- Tag by quarter: "Q1 2026", "Q2 2026"

**If multiple tags supported:**
- Apply both: "Engineering" + "Q2 2026"

**If single tag only:**
- Use compound tags: "Engineering Q2 2026"

**Benefit:** Easy to find scenarios by team and time period.

---

### Strategy 2: Purpose-Based Tagging

**Setup:**
- Tag by planning purpose: "Hiring", "Reorgs", "Budget Cuts", "Succession"

**When to use:**
- Organization focuses on specific planning activities
- Want to track all hiring scenarios across departments
- Compare similar scenarios across teams

**Benefit:** See all scenarios of same type across organization.

---

### Strategy 3: Workflow Status Tagging

**Setup:**
- Tag by status: "Draft", "In Review", "Approved", "Implemented"

**When to use:**
- Tracking scenarios through approval process
- Quickly identify what needs attention
- Reporting on planning pipeline

**Benefit:** Clear visibility into scenario lifecycle stages.

---

### Strategy 4: Hybrid Approach

**Setup:**
- Combine multiple strategies
- Example: "Engineering - Q2 2026 - Hiring"

**When to use:**
- Complex organization with many scenarios
- Need detailed categorization
- Multiple stakeholders with different filtering needs

**Benefit:** Maximum flexibility for filtering and organization.

## Best Practices

1. **Establish conventions early** - Agree on tag naming and structure
2. **Be consistent** - Use same format across all scenarios
3. **Don't over-tag** - Too many tags can be as confusing as none
4. **Clean up regularly** - Delete or archive old tags (e.g., previous quarters)
5. **Document tag meanings** - Ensure team understands tag system
6. **Use tags with naming** - Tags complement clear scenario names
7. **Review tag structure quarterly** - Adjust as organization needs change

## Common Workflows

### Workflow 1: Quarterly Planning Preparation

**Goal:** Organize all Q2 scenarios for review

**Steps:**
1. Tag all Q2 scenarios with "Q2 2026"
2. Filter scenario list by "Q2 2026"

2. Filter by "Engineering"

4. VP can quickly see all relevant scenarios
5. Discuss and prioritize together

---

**Goal:** Archive old tags and clean up scenario list

**Steps:**
1. Review all tags from previous year
2. Delete tags for old quarters (e.g., "Q1 2025", "Q2 2025")
3. Archive scenarios with old tags
4. Create new tags for upcoming year
5. Update current scenarios with new tags

## Troubleshooting

**Problem:** Tags not appearing on scenario.
- **Solution:** Ensure tag was saved. Refresh page. Check permissions.

**Problem:** Can't create new tag.
- **Solution:** May need admin permissions. Contact admin or ask them to create tag.

**Problem:** Filter not working.
- **Solution:** Clear all filters and try again. Refresh page. Ensure scenarios have correct tags.

**Problem:** Too many tags, can't find what I need.
- **Solution:** Consolidate tags. Delete redundant tags. Establish clearer conventions.

**Problem:** Scenario has wrong tag.
- **Solution:** Click ⋮ menu, change tag to correct one. Check if others have same issue.
