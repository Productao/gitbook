# Scenario Tags

Tags help you organize and filter scenarios by department, quarter, project, or status.

---

## Adding Tags to Scenarios

1. Click **⋮** menu on any scenario
2. Select **Add Tag** or **Change Tag**
3. Choose existing tag from dropdown OR type new tag name
4. Press **Enter**

The tag appears as a colored label on the scenario card for visual organization.

---

## Common Tag Examples

**By Department:**
- Engineering, Sales, Marketing, Product, Operations, Finance

**By Planning Cycle:**
- Q1 2026, Q2 2026, H1 2026, FY27

**By Purpose:**
- Budget Cuts, Growth Plans, Reorgs, Hiring, Succession

**By Status:**
- Draft, In Review, Approved, Implemented

**By Project:**
- AI Initiative, Expansion EMEA, GTM Realignment

**Tip:** Use consistent naming conventions across your organization (e.g., always "Q1 2026" not "q1-2026").

---

## Managing Tags

### Removing a Tag from a Scenario

1. Click **⋮** menu on scenario
2. Select **Change Tag**
3. Select **No Tag** or clear selection
4. Save

### Renaming or Deleting Tags (Admin)

**Access:** Settings > Tags (if available in your system)

**Rename:** Changes the tag name across all scenarios that use it.

**Delete:** Removes the tag from all scenarios permanently.

> **Note:** Tag management features may require admin permissions. Contact your admin if you need to rename or delete organization-wide tags.

---

## Best Practices

- **Be consistent:** Agree on tag naming conventions with your team
- **Don't over-tag:** Use 3-5 tag categories maximum
- **Clean up regularly:** Archive or delete tags for old quarters/completed projects
- **Combine with scenario names:** Tags complement clear scenario naming, don't replace it

---

## Multiple Tags

Some systems support multiple tags per scenario (e.g., "Engineering" + "Q2 2026" + "Hiring"). Check with your admin to see if this is enabled for your organization.

If only single tags are supported, use compound tags like "Engineering - Q2 2026".
