# Real-Time Co-Editing

Multiple users can work in the same scenario simultaneously. Agentnoon provides real-time synchronization, presence indicators, and conflict prevention features to make collaborative scenario building seamless and efficient.

---

## How Real-Time Collaboration Works

**Multiple users can edit the same scenario simultaneously.**

**How it works:**
1. User A and User B both open the same scenario
2. User A adds a position in Engineering
3. User B sees the change appear immediately
4. User B closes a position in Marketing
5. User A sees the closure immediately
6. Changes sync in real-time

**Benefits:**
- Faster scenario building through parallel work
- No need to wait for one person to finish
- Immediate feedback on changes
- Coordinated planning across departments

---

## See Who's Online

When multiple users work in the same scenario, Agentnoon shows who's active.

**What you see:**
- **Profile icons** appear at top of scenario
- Each icon represents an active collaborator
- Hover over icon to see name
- See their cursor/activity in real-time (if enabled)

**Why this helps:**
- Avoid conflicting edits
- Coordinate who's working on what
- Know when to communicate before making big changes
- See real-time engagement

## Collaborative Editing Best Practices

### Coordinate Before Starting

**Best practice:** Communicate who's working on what section.

**Example:**
1. Planner A: "I'll work on Engineering org"
2. Planner B: "Got it, I'll handle Sales and Marketing"
3. Both work in parallel without conflicts
4. Changes sync seamlessly

**Use comments to coordinate:**
- Add general comment announcing your focus area
- @mention co-planner to confirm division of work
- Update comment when switching sections

---

### Handle Simultaneous Edits

**What happens if two users edit the same position?**
- Last save wins
- Previous changes are overwritten

**How to prevent:**
1. **Communicate** - Use comments to say what you're working on
2. **Check presence** - See who else is online before editing
3. **Work in different areas** - Divide scenario by department/function
4. **Review together** - Walk through changes when both done

---

### Use Comments for Coordination

**Scenario:** Two planners building scenario together.

**Communication flow:**
- Planner A: "Starting on Engineering reorg now"
- Planner B: "Ok, I'm reviewing Sales structure first"
- Planner A: "@plannerB I need your input on Product - can you look when you're done with Sales?"
- Planner B: "On it - should be done in 10 minutes"
- Planner A: "Perfect, I'll wait to avoid conflicts"

**Result:** Clear communication prevents wasted work.

## Common Co-Editing Workflows

### Workflow 1: Parallel Department Planning

**Goal:** Two planners build scenario simultaneously, each handling different departments.

**Steps:**
1. Planner A creates scenario
2. Planner A shares with Planner B (Edit Access)
3. Planner A adds comment: "I'm working on Engineering, you handle Sales"
4. Both see each other's profile icons at top
5. Planner A adds/edits positions in Engineering
6. Planner B adds/edits positions in Sales simultaneously
7. Changes sync in real-time
8. Both see complete picture as they work
9. When done, both review together
10. Submit for approval

**Result:** Scenario built in half the time.

---

### Workflow 2: Build and Review

**Goal:** One planner builds, another reviews in real-time.

**Steps:**
1. Planner A (builder) creates scenario
2. Planner A shares with Manager B (Edit Access)
3. Planner A starts making changes
4. Manager B opens scenario (sees profile icon)
5. Manager B watches changes appear in real-time
6. Manager B adds comments on specific positions as Planner A works
7. Planner A sees comments immediately and addresses
8. Iterate until Manager B approves
9. Submit scenario

**Result:** Real-time feedback and approval.

---

### Workflow 3: Workshop Session

**Goal:** Team of 3 builds scenario together in meeting.

**Steps:**
1. Lead creates scenario on projector/screenshare
2. Lead shares with 2 team members (Edit Access)
3. Team discusses approach
4. Lead makes structural changes
5. Team Member 1 handles headcount details
6. Team Member 2 adds position comments with context
7. All 3 see changes in real-time
8. Discuss and iterate together
9. Complete scenario in one session

**Result:** Collaborative workshop with immediate results.

---

### Workflow 4: Handoff Between Time Zones

**Goal:** Global team works across time zones.

**Steps:**
1. US planner works on scenario (8am-5pm PST)
2. Shares with EMEA planner (Edit Access)
3. EMEA planner continues work (5pm PST - 2am PST)
4. Adds comment summarizing what they did
5. US planner reviews next morning
6. Sees all changes from overnight
7. Continues work and responds to comments
8. Seamless 24-hour workflow

**Result:** Continuous progress across time zones.

### Resolving Conflicts

**If two users edit the same position simultaneously:**

**What happens:**
- Last save wins
- One user's changes overwrite the other

**How to fix:**
1. Notice the discrepancy
2. Check Change Tracker to see what happened
3. One user adds comment: "@user I think my change overwrote yours - can you redo?"
4. Affected user re-applies their change
5. Other user confirms

**Prevention:**
- Communicate before editing same positions
- Work in different sections
- Use comments to claim sections: "Working on Engineering now"

## Troubleshooting

**Problem:** Can't see other users' profile icons.
- **Solution:** Feature may be disabled by admin. Or users may not be actively in the scenario at that moment. Refresh page.

**Problem:** Changes not syncing in real-time.
- **Solution:** Check internet connection. Refresh page. Ensure both users have Edit Access.

**Problem:** Two users edited same position, now data is wrong.
- **Solution:** Last save wins. Check Change Tracker to see what happened. Undo and re-apply correct change. Use comments to coordinate before editing.

**Problem:** Other user's changes disappeared.
- **Solution:** Changes may have been overwritten by simultaneous edit (last save wins). Check Change Tracker. Re-apply changes if needed.

**Problem:** Too many people editing at once causing confusion.
- **Solution:** Limit concurrent editors to 2-3. Use comments to coordinate who's working on what. Consider sequential rather than parallel work for complex scenarios.

**Problem:** Want to work offline and sync later.
- **Solution:** Agentnoon requires online connection for real-time sync. Work offline is not supported. Consider duplicating scenario to work independently.

## Best Practices Summary

1. **Communicate first** - Discuss who's working on what before starting
2. **Use comments** - Announce what you're working on
3. **Divide by section** - Work in different departments/functions
4. **Check who's online** - See profile icons before making big changes
5. **Review together** - Walk through final scenario as team
6. **Last save wins** - Remember this when editing same position
7. **Limit concurrent editors** - 2-3 people max for best experience
8. **Use Change Tracker** - Review who made what changes
