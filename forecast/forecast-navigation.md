# Forecast Navigation

### Overview

This guide explains how to use the **Forecast** screen in Agentnoon, both in the **main organization** and within **scenarios**, to analyze headcount and cost projections over time.

### Navigating to the Forecast Screen

1. Open the **Org Chart** dropdown.
2. Select **Forecast** to access the forecast dashboard.

### Forecast UI & Key Features

#### 1. Grouping Data

* Choose how data is grouped:
  * **People** (individual employees).
  * **Departments, Entities, or other custom attributes** (based on imported data).

#### 2. Headcount vs. Headcount Cost

* **Headcount View**:
  * `1` = Active employee during a specific time period.
  * `0` = Inactive employee.
* **Headcount Cost View**: Displays financial projections for workforce costs.

#### 3. Filters & Search

* Apply **filters** to view specific employees, teams, or attributes.
* Use **search** to find an employee or position quickly.

#### 4. Time Period Selection

* Toggle between **Monthly, Quarterly, or Yearly** forecasts.
* Select the **year** you want to analyze.

#### 4. Export

* Export data as a CSV file

### Understanding the Forecast Table

* **Group Column**: Displays **People, Departments, or Entities**, based on selection.
* **Status Column**: Indicates if an employee or position is **Active or Inactive**.
* **Currency Column**: Displays the currency of salary or costs.
* **Start & End Dates**:
  * Determines **when** an employee or position **becomes active** in the forecast.
  * If a person **starts in April**, they appear as **inactive** before April and **active** from April onwards.
  * The **end date** determines when they **exit the forecast**.

### Forecasting in Scenarios

Inside a scenario, forecasting updates dynamically based on **hiring and termination decisions**:

* **Editing a Position**:
  1. Click the **Edit** button for any position.
  2. Scroll to the **bottom** of the edit panel to define:
     * **Hire/Start Date** (for new hires).
     * **Termination Date** (for reductions).
* **Real-Time Updates**:
  * Changes to **hire or termination dates** immediately reflect in the scenario forecast.
  * Financial projections **update in real-time** to show the impact of workforce changes.
