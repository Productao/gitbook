# Quick Start Guide

Welcome! This guide will help you master the essential features of Agentnoon in just 30 minutes.

## 🎯 Your Learning Path

Complete these 10 core tasks to become production-ready:

### 1. Log In and Navigate the Homepage

When you first log into Agentnoon, you'll see the **homepage** with:
- Your instance name at the top
- A list of scenarios in the center (may be empty initially - you'll be prompted to create one)
- Quick links to documentation and support
- A connection speed test tool

### 2. Explore the Main Organization

Click into your organization to see:
- **Cards** representing positions or people
- The organizational hierarchy
- Quick stats like span of control and team size

**Navigation tips:**
- Hover over cards to see details
- Click to expand/collapse reporting lines
- Use search to find specific positions

### 3. Search for a Person or Position

Use the search bar to find anyone in your organization:
1. Start typing a name or job title
2. Results appear as you type
3. Click a result to navigate directly to that position

### 4. Add Card Content

Customize what information appears on each card:
1. Click the **card content** button
2. Select which fields to display (work city, department, salary, etc.)
3. Cards update immediately to show your selections

**Pro tip:** Add FX (calculated) fields like Total Span of Control for instant insights!

### 5. Create a Custom View with Highlights and Filters

Make the org chart work for you:

**Highlighting:**
1. Click the highlight button
2. Choose a field (e.g., Work Country, Department)
3. Cards color-code automatically by value
4. Add a legend for easy reference

**Filtering:**
1. Click the filter button
2. Select criteria (department, location, etc.)
3. Apply to focus on specific parts of your org
4. Preserve manager relationships option keeps context intact

### 6. Use Spotlight to Find Patterns

Spotlight helps you discover organizational insights:
1. Click the Spotlight button
2. Choose from pre-configured rules:
   - Average span of control ranges
   - Specific pay grades
   - Custom field values
3. Matching positions highlight automatically
4. View list of all matching positions

### 7. Create Your First Scenario

Scenarios let you model changes before implementing them:
1. From homepage, click "Create Scenario"
2. Choose scenario type:
   - **Full Org** - includes everyone in your scope
   - **Partial Org** - select specific departments/teams
   - **New Org** - start from blank canvas
3. Name your scenario descriptively
4. Set effective date (optional)
5. Click Create

### 8. Make Position Changes in a Scenario

Once in a scenario, try these basic edits:
- **Add a position:** Hover over a card, click the + button
- **Edit position details:** Click the card, modify fields
- **Move a position:** Drag and drop to new manager
- **Close a position:** Select card, click RIF/Exit

### 9. Join Two Managers into One

Practice organizational restructuring:
1. Select the team you want to move
2. Click "Change Manager"
3. Choose the new manager from dropdown
4. Team moves instantly - changes tracked automatically

### 10. Export a Chart to PowerPoint

Share your analysis with stakeholders:
1. Navigate to **Workforce Hub**
2. Select a chart (e.g., Headcount Distribution)
3. Click the download button
4. Choose "PowerPoint slide"
5. The chart exports as an editable PowerPoint element

## ✅ You're Ready!

If you can complete these 10 tasks, you're ready to use Agentnoon effectively!
