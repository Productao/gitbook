# Hub Overview

### What is the Workforce Hub?

The **Workforce Hub** is Agentnoon's analytics and insights center where workforce data comes to life through powerful visualizations and interactive charts. It provides a centralized location for analyzing organizational structure, headcount distribution, spans of control, layers, and workforce costs.

### When to Use the Workforce Hub

The Workforce Hub is particularly valuable when:

* **Preparing for budget conversations** with department leaders and stakeholders
* **Identifying opportunities** for organizational efficiency improvements
* **Analyzing managerial spans** and identifying potential compression or span issues
* **Understanding headcount distribution** across departments, locations, or pay grades
* **Conducting structural analysis** to rationalize organization design
* **Creating presentations** with data-driven insights for leadership

### Accessing the Workforce Hub

1. Log into Agentnoon and navigate to your organization
2. Click on the **Workforce Hub** option in the main navigation
3. You'll immediately see pre-configured charts ready to provide insights

### Key Features

#### Chart Library

The Hub provides several pre-configured charts designed to add immediate value:

* **Layers and Spans of Control** - Analyze managerial structures and identify span issues
* **Headcount Distribution** - View workforce distribution across various dimensions
* **Headcount Heatmap** - Visualize headcount density across layers and departments
* **Org Map** - See proportional headcount splits across the organization
* **Cost Analysis Charts** - Understand workforce expenses and budget allocation
* **Span of Control Distribution** - Group managers by span sizes

#### Interactive Controls

Every chart in the Workforce Hub includes:

* **Chart selector dropdown** - Switch between different chart types
* **X-axis and Y-axis configuration** - Customize data dimensions
* **Filters** - Focus on specific departments, locations, or attributes
* **Settings gear icon** - Access chart-specific customization options
* **Export options** - Download as PNG, PowerPoint, or CSV
* **Show table function** - View raw data behind the visualizations

#### Filter Persistence

Filters applied in the Workforce Hub are **respected across all views**, including:

* When switching between different charts
* When navigating back to the org chart
* When creating slide packs

**Important**: If you're seeing unexpected data, always check your active filters.

### Common Workflows

#### 1. High-Level Analysis Workflow

1. Start in the **Workforce Hub** to get a bird's-eye view
2. Use aggregate charts like **Layers and Spans of Control** to identify patterns
3. Apply filters to focus on specific departments or areas
4. Note areas of concern or opportunity

#### 2. Detailed Discovery Workflow

1. Begin with Hub charts to identify potential issues
2. Navigate to the **Org Chart** view
3. Use **Spotlight** rules to drill into specific positions
4. Analyze individual manager situations and context
5. Return to Hub to verify impact of potential changes

#### 3. Presentation Workflow

1. Configure charts with relevant filters and settings
2. Export individual charts or create a **Slide Pack**
3. Download as PowerPoint for executive presentations
4. Use CSV exports for detailed data analysis

### Navigation Tips

* Use the **Go to Hub** button (top-right) to return to the chart library
* Use keyboard shortcuts: Press **1-5** to jump between main sections
* The **show table** function reveals position-level breakdowns
* Click on chart elements for interactive filtering (chart-specific)

### Best Practices

* **Check filters first** - Always verify what data is in scope before analysis
* **Use multiple chart types** - Different charts reveal different insights
* **Export early and often** - Save snapshots of analysis for reference
* **Combine with org chart** - Use Hub for high-level, org chart for details
* **Consider context** - Numbers alone don't tell the story; understand the business context
