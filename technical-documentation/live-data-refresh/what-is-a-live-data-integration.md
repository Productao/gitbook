# What is a Live Data Integration?

### Overview

Real-time data integration synchronizes data from multiple sources on a defined, customer-configured refresh cadence. This ensures that recent data is available for analysis and operational use without requiring manual updates.

### Key Features

* **Configurable Data Refresh:** Data is refreshed on a schedule defined by the customer, allowing systems and analyses to stay aligned with the most recent available information.
* **Reduced Data Silos:** Integrated data is made available in a unified view, making it easier to access and analyze information that would otherwise reside in separate systems.
* **Secure Data Transfer:** Data is transferred using secure, automated processes that support large-scale ingestion into Agentnoon while maintaining data integrity and protection.
