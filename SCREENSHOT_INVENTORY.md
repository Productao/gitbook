## Screenshot Capture Guidelines

### Technical Requirements
- **Resolution:** Minimum 1920x1080, capture at actual resolution (no scaling)
- **Format:** PNG preferred for UI screenshots (lossless compression)
- **Browser:** Use Chrome or Firefox, latest version
- **Zoom Level:** 100% (default browser zoom, no zooming in/out)
- **Theme:** Use default Agentnoon theme (light mode unless dark mode is default)
- **Privacy:** Ensure all test data contains no real employee information or sensitive data

### Data Requirements
- Use realistic but fake data (e.g., "Jane Smith" not "Test User 123")
- Company name: Use "Acme Corp" or "Example Company" consistently
- Employee count: Show realistic numbers (100-1000 employees for most examples)
- Salary ranges: Use realistic but rounded numbers ($100K, $150K, not $73,429)
- Departments: Engineering, Sales, Marketing, Product, Finance, HR, Operations
- Locations: San Francisco, New York, London, Remote (mix for variety)

### Composition Guidelines
- **Focus:** Center the relevant UI element, remove unnecessary chrome/navigation when possible
- **Annotations:** No arrows or callouts in screenshots - these go in the documentation text
- **Highlighting:** Let Agentnoon's built-in highlighting show (e.g., color-coded changes)
- **Context:** Include enough surrounding UI to orient users (keep top nav bar when relevant)
- **Consistency:** Use the same test data set across related screenshots when possible

### Naming Convention
Name screenshot files using this pattern:
```
[section]-[page]-[description].png
```

Examples:
- `start-here-welcome-platform-overview.png`
- `scenarios-overview-change-tracker.png`
- `main-org-navigation-left-toolbar.png`
