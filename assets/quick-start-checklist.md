# Quick Start Checklist

Use these checklists to get up and running with Agentnoon. Track your progress as you learn the platform and complete key onboarding tasks.

---

## Day 1: First Login & Basic Navigation

**Goal:** Get logged in and familiarize yourself with the Agentnoon interface.

### ✅ Getting Started
- [ ] **Log in to Agentnoon** using SSO or email/password
- [ ] **Complete profile setup** (if prompted)
- [ ] **Read the Welcome page** ([Welcome to Agentnoon](../start-here/welcome.md))
- [ ] **Watch intro video** (if available in [Video Tutorials](../start-here/video-tutorials.md))

### ✅ Explore Main Org
- [ ] **Click "Open Org"** to view your organizational structure
- [ ] **Switch between org chart and directory views** (use dropdown at top)
- [ ] **Search for yourself** (use Search button in left taskbar)
- [ ] **Find your manager** in the org chart
- [ ] **Count your manager's direct reports** (learn about Span of Control)

### ✅ Learn the Taskbar
- [ ] **Open the Filter tool** and filter by your department
- [ ] **Try the Highlight tool** to color-code by department or location
- [ ] **Customize Card Content** to show fields you care about (salary, title, etc.)
- [ ] **Clear all filters** to return to full view

### ✅ Read Key Concepts
- [ ] **Read [Key Concepts](../start-here/concepts.md)** (10 minutes)
- [ ] Understand: **Positions vs. People**
- [ ] Understand: **Main Org vs. Scenarios**
- [ ] Understand: **Span of Control (SOC)**

---

## Week 1: Understanding Your Data

**Goal:** Learn how Agentnoon works and explore your organizational data.

### ✅ Explore Data Views
- [ ] **View Directory** (spreadsheet-style table of all positions)
- [ ] **Sort by salary** (highest to lowest)
- [ ] **Filter by location** to see geographic distribution
- [ ] **Export to CSV** and open in Excel (practice exporting data)

### ✅ Learn About Scenarios
- [ ] **Read [Scenarios Overview](../scenarios/overview.md)** (15 minutes)
- [ ] Understand: What scenarios are and when to use them
- [ ] Understand: Scenarios don't affect Main Org
- [ ] Understand: How to submit scenarios for approval

### ✅ Learn About Forecast
- [ ] **Read [Forecast Overview](../forecast/overview.md)** (10 minutes)
- [ ] **Open Forecast view** (use dropdown at top: Directory → Forecast)
- [ ] **Try different aggregators** (Department, Location, Employee Type)
- [ ] **Switch between headcount and cost views**
- [ ] **Change time period** (Monthly, Quarterly, Yearly)

### ✅ Watch Training Videos
- [ ] **Watch "Creating Your First Scenario"** (if available)
- [ ] **Watch "Understanding Forecast"** (if available)
- [ ] Browse [Video Tutorials](../start-here/video-tutorials.md) for additional learning

## Your First Scenario: Practice Planning

**Goal:** Create a practice scenario to learn how workforce planning works.

### ✅ Create a Test Scenario
- [ ] **Click "Create Scenario"** button
- [ ] **Name it:** "Practice Scenario - DELETE ME"
- [ ] **Choose Full Org** (copy entire organization)
- [ ] **Add a description:** "Learning how scenarios work"
- [ ] **Click Create**

### ✅ Make Practice Changes
- [ ] **Add a new position**:
  - Navigate to a team in the org chart
  - Click "+ Add Position"
  - Fill in title, salary, manager
  - Save
- [ ] **Close a position**:
  - Right-click a position
  - Select "Close Position"
  - Confirm
- [ ] **Move a position**:
  - Drag a position card to a new manager
  - Or change the "Manager" field in position details

### ✅ Analyze Impact
- [ ] **Open the OpEx Panel** (Scenario Impacts and Changes)
- [ ] **View net headcount change** (+/- positions)
- [ ] **View net cost change** (+/- workforce cost)
- [ ] **See list of changes** (additions in green, closures in red)

### ✅ View in Forecast
- [ ] **Switch to Forecast view** (dropdown at top)
- [ ] **Select "Show Before"** (Main Org baseline)
- [ ] **Select "Show After"** (your scenario)
- [ ] **Select "Show Changes"** (delta between before/after)
- [ ] **Export to CSV** to see the data in Excel

### ✅ Clean Up
- [ ] **Delete your practice scenario** (three-dot menu → Delete Scenario)
- [ ] **Confirm deletion**

**Congrats!** You've completed your first scenario workflow.

## Admin Onboarding Checklist

**For Agentnoon Admins Only**

### ✅ Week 1: Setup & Familiarization

- [ ] **Configure default views** for different user types

### ✅ Week 3: Data & Configuration
- [ ] **Set up regular data refresh schedule**
- [ ] **Configure rate cards** (if applicable)

- [ ] **Read [Configuring Approval Flows](../admin/configuring-approval-flows.md)**

## Department Lead Checklist

**For Managers Planning Department Changes**

### ✅ Quarterly Planning
- [ ] **Create scenario** named "[Quarter] [Year] [Department] Plan"
- [ ] **Model hiring needs**:
  - Add positions with hire dates for phased hiring
  - Assign salaries (use rate cards if available)
  - Set reporting relationships
- [ ] **Model attrition**:
  - Close positions expected to turn over
  - Set termination dates if known
- [ ] **Analyze cost impact** in OpEx Panel
- [ ] **View in Forecast** to see monthly/quarterly ramp
- [ ] **Export forecast data** for budget meetings
- [ ] **Submit for approval** via OpEx Panel

### ✅ Organizational Changes
- [ ] **Create scenario** describing the change (reorg, restructure, etc.)
- [ ] **Model new structure**:
  - Add new positions (managers, team leads)
  - Move existing positions to new reporting relationships
  - Close redundant positions
- [ ] **Check Span of Control** for all managers
- [ ] **Use effective dates** to phase changes over time
- [ ] **Get stakeholder feedback** before submitting
- [ ] **Submit for approval**

**Learn more:** [Planning a Reorganization](../use-case-tutorials/planning-reorganization.md)

## Workforce Planner Checklist

**For HR/Finance Planning Teams**

### ✅ Annual Planning Cycle
- [ ] **Review prior year actuals** vs. plan
- [ ] **Gather inputs** from department leaders
- [ ] **Create "FY[Year] Workforce Plan" scenario**
- [ ] **Model growth by department**:
  - Add positions by quarter with hire dates
  - Use rate cards for salary consistency
  - Align to revenue/headcount targets
- [ ] **Model cost increases**:
  - Merit increases (3% typical)
  - Promotions
  - Market adjustments
- [ ] **View in Forecast** (Yearly view, 3-5 years)
- [ ] **Compare scenarios** (Conservative vs. Aggressive growth)
- [ ] **Export for executive presentation**
- [ ] **Submit for CFO approval**

### ✅ Budget Cuts / RIF Planning
- [ ] **Create "Budget Reduction" scenario**
- [ ] **Set target savings** in scenario budget (-$XM)
- [ ] **Identify positions to close**:
  - Use Directory filters (sort by cost, department)
  - Select positions strategically
  - Bulk close positions
- [ ] **Analyze org impact**:
  - Check Span of Control after cuts
  - Identify broken reporting relationships
  - Assess critical role retention
- [ ] **Compare multiple cut scenarios** (Option A, B, C)
- [ ] **Model implementation timeline** with effective dates
- [ ] **Submit for executive approval**

**Learn more:** [Budget Planning & Tracking](../forecast/budget-planning-tracking.md)

## Quarterly Planning Checklist

**For Regular Planning Cycles**

### ✅ Pre-Quarter Planning (Month 3 of prior quarter)
- [ ] **Review current quarter performance** (hiring, attrition, budget)
- [ ] **Gather inputs from department leaders**
- [ ] **Identify needs**:
  - New positions to add
  - Backfills for expected attrition
  - Reorgs or restructures
- [ ] **Refresh Main Org data** (admin uploads latest HRIS export)

### ✅ Scenario Creation (Month 1 of quarter)
- [ ] **Create "[Quarter] [Year] Plan" scenario**
- [ ] **Model all changes**:
  - Add new positions with hire dates
  - Close positions for attrition
  - Move positions for reorgs
  - Set effective dates for phased changes
- [ ] **Check budget** in OpEx Panel
- [ ] **View in Forecast** (quarterly view)

### ✅ Approval & Implementation (Month 1-2)
- [ ] **Export forecast data** for stakeholder presentations
- [ ] **Submit scenario for approval**
- [ ] **Wait for approvals** (Level 0/1/2/3)
- [ ] **If rejected:** Address feedback and resubmit
- [ ] **If approved:** Implement in real world (post jobs, conduct RIFs, etc.)
- [ ] **Update Main Org** (admin uploads current data)

### ✅ Monitoring (Throughout quarter)
- [ ] **Track hiring progress** vs. plan
- [ ] **Track attrition** vs. expectations
- [ ] **Update forecast** if needed (create new scenario version)
- [ ] **Report actuals** to Finance and leadership

---

## Annual Planning Checklist

**For Fiscal Year Planning**

### ✅ Pre-Planning (Q3 of prior fiscal year)
- [ ] **Review current fiscal year** performance
- [ ] **Set targets** for next fiscal year (headcount, budget)
- [ ] **Gather inputs** from all departments
- [ ] **Refresh Main Org data**

### ✅ Scenario Development (Q4 of prior fiscal year)
- [ ] **Create "FY[Year] Plan" scenario**
- [ ] **Model entire fiscal year**:
  - Add all new positions with hire dates by quarter
  - Model promotions and merit increases
  - Close positions for planned attrition
- [ ] **Align to budget targets** (OpEx Panel)
- [ ] **View in Forecast** (Yearly + breakdown by quarter)
- [ ] **Create scenario variants** (Conservative, Moderate, Aggressive)

### ✅ Approval & Finalization (Q4 / Q1)
- [ ] **Present to CFO and Finance**
- [ ] **Present to CEO and Executive Team**
- [ ] **Submit for formal approval**
- [ ] **Finalize and communicate** to organization
- [ ] **Set up quarterly reviews** to track progress

**Learn more:** [Multi-Year Planning](../forecast/multi-year-planning.md)
