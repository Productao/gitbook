# Quick Start Checklist

Get up and running with Agentnoon quickly. This checklist covers the essentials you need to know on Day 1 and your first week.

**Total estimated time: 2-3 hours**

---

## Day 1: First Login (30 minutes)

Get logged in and explore the basics.

1. Log in to Agentnoon using SSO or email/password
2. Complete your profile setup if prompted
3. Click "Open Org" to view your organizational structure
4. Search for yourself using the Search button in the left taskbar
5. Find your manager in the org chart
6. Switch between org chart and directory views using the dropdown at top
7. Read the [Welcome to Agentnoon](../start-here/welcome.md) page

**You've completed the basics!** You can now navigate the platform.

---

## Day 1: Learn the Interface (45 minutes)

Understand the main tools and views.

### Explore the Taskbar (15 minutes)

1. Open the Filter tool and filter by your department
2. Try the Highlight tool to color-code by department or location
3. Customize Card Content to show fields you care about (salary, title, etc.)
4. Clear all filters to return to full view

### Understand Core Concepts (20 minutes)

Read [Key Concepts](../start-here/concepts.md) to understand:
- Positions vs. People
- Main Org vs. Scenarios
- Span of Control (SOC)

### Try Different Views (10 minutes)

1. View Directory (spreadsheet-style table of all positions)
2. Sort by salary (highest to lowest)
3. Filter by location to see geographic distribution
4. Export to CSV and open in Excel

**You now understand the basic interface!**

---

## First Week: Create Your First Scenario (60 minutes)

Learn how workforce planning works by creating a practice scenario.

### Create a Test Scenario (10 minutes)

1. Click "Create Scenario" button
2. Name it: "Practice Scenario - DELETE ME"
3. Choose Full Org (copy entire organization)
4. Add description: "Learning how scenarios work"
5. Click Create

Read [Scenarios Overview](../scenarios/overview.md) to understand what scenarios are and when to use them.

### Make Practice Changes (20 minutes)

Try these basic operations:

**Add a new position:**
1. Navigate to a team in the org chart
2. Click "+ Add Position"
3. Fill in title, salary, manager
4. Save

**Close a position:**
1. Right-click a position
2. Select "Close Position"
3. Confirm

**Move a position:**
1. Drag a position card to a new manager
2. Or change the "Manager" field in position details

### Analyze Impact (15 minutes)

1. Open the OpEx Panel (Scenario Impacts and Changes)
2. View net headcount change (+/- positions)
3. View net cost change (+/- workforce cost)
4. See list of changes (additions and closures)

### View in Forecast (10 minutes)

1. Switch to Forecast view (dropdown at top)
2. Select "Show Before" (Main Org baseline)
3. Select "Show After" (your scenario)
4. Select "Show Changes" (delta between before/after)
5. Export to CSV to see the data in Excel

Read [Forecast Overview](../forecast/overview.md) to learn more.

### Clean Up (5 minutes)

1. Delete your practice scenario (three-dot menu → Delete Scenario)
2. Confirm deletion

**Congrats!** You've completed your first scenario workflow and understand the core planning process.
