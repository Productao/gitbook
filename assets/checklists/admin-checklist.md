# Admin Checklist

Complete guide for Agentnoon administrators setting up and managing the platform.

**Total estimated time: 4 weeks (ongoing)**

---

## Week 1: Setup & Familiarization

**Estimated time: 8-10 hours**

### Training & Initial Setup (3 hours)

1. Complete Agentnoon admin training with customer success team
2. Review your organization's current data structure and fields
3. Understand your existing access control setup
4. Read [Admin Overview](../../admin/overview.md)

### Data & Configuration (3 hours)

1. Test data upload process with a sample file
2. Review [Data Requirements](../../data-import/data-requirements.md)
3. Check [Calculated Agentnoon Attributes](../../data-import/calculated-agentnoon-attributes.md)
4. Explore Settings pages to understand all configuration options

### Platform Familiarization (2-4 hours)

1. Complete the main [Quick Start Checklist](../quick-start-checklist.md)
2. Create a test scenario to understand the user experience
3. Practice navigating Main Org, Scenarios, and Forecast views

---

## Week 2: User Management

**Estimated time: 6-8 hours**

### User Setup (3-4 hours)

1. Invite key users (HR, Finance, Operations leaders)
2. Create admin accounts for other power users
3. Read [User Invitations](../../access-control/user-invitations.md)

### Access Control Configuration (3-4 hours)

1. Create access groups for departments or regions
2. Configure default views for different user types
3. Test access restrictions to ensure proper permissions
4. Read [Access Groups](../../access-control/access-groups.md)
5. Review [Advanced Access Controls](../../access-control/advanced-access-controls.md)

---

## Week 3: Data & Configuration

**Estimated time: 8-10 hours**

### Data Management (4-5 hours)

1. Set up regular data refresh schedule with your HRIS team
2. Document your data refresh process
3. Create a data error checklist for troubleshooting
4. Read [Data Refresh & Sync](../../admin/data-refresh-sync.md)
5. Review [Data Error Checklist](../../data-import/data-error-checklist.md)

### Advanced Configuration (4-5 hours)

1. Configure rate cards for consistent salary planning (if applicable)
2. Set up auto mapping rules for common position changes
3. Create custom fields specific to your organization's needs
4. Read [Rate Cards / Compensation Bands](../../settings/compensation-cards.md)
5. Read [Auto Mapping](../../settings/automapping.md)
6. Review [Fields and Attributes Management](../../settings/fields.md)

---

## Week 4: Approval Workflows & Training

**Estimated time: 8-10 hours**

### Approval Configuration (3-4 hours)

1. Configure approval workflows (Level 1 & 2 approvers)
2. Test scenario approval process end-to-end
3. Document approval procedures for your organization
4. Read [Configuring Approval Flows](../../admin/configuring-approval-flows.md)
5. Review [Scenario Approvals](../../scenarios/approvals.md)

### User Training & Documentation (5-6 hours)

1. Train power users on creating scenarios
2. Create internal documentation for your organization's specific workflows
3. Set up office hours or support channel for user questions
4. Share relevant checklists with different user groups:
   - [Department Lead Checklist](department-lead-checklist.md)
   - [Workforce Planner Checklist](workforce-planner-checklist.md)

---

## Ongoing Admin Tasks

### Weekly

- Monitor user activity and address questions
- Check for data upload errors
- Review pending scenario approvals

### Bi-weekly

- Refresh Main Org data from HRIS
- Review access group memberships
- Check for new feature releases

### Monthly

- Audit user permissions and access
- Review and update rate cards
- Clean up old scenarios (archive or delete)
- Generate usage reports for leadership

### Quarterly

- Review admin procedures and update documentation
- Conduct admin training refresher
- Evaluate new features and configuration options
- Gather feedback from power users
