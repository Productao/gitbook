# Quarterly Planning Checklist

Standard workflow for regular quarterly workforce planning cycles.

**Total estimated time: 4-6 hours per quarter**

---

## Month 3 of Prior Quarter: Pre-Planning

**Estimated time: 1-2 hours**

Prepare for next quarter's planning cycle.

### Review Current Quarter (45 minutes)

1. Review current quarter performance:
   - Hiring progress vs. plan
   - Actual attrition vs. expectations
   - Budget spend vs. forecast
2. Identify lessons learned and adjustments needed
3. Document any surprises or trends

### Gather Planning Inputs (45 minutes)

1. Request updates from all department leaders:
   - New positions needed
   - Backfills for expected attrition
   - Any reorganizations or restructures planned
2. Get updated budget guidance from Finance
3. Understand strategic priorities from leadership

### Data Refresh (15 minutes)

1. Coordinate with admin to refresh Main Org data
2. Verify latest HRIS export is loaded
3. Confirm all recent changes are reflected

---

## Month 1 of Quarter: Scenario Creation

**Estimated time: 2-3 hours**

Create the quarterly workforce plan.

### Create Quarterly Scenario (15 minutes)

1. Click "Create Scenario"
2. Name it: "[Quarter] [Year] Plan" (e.g., "Q2 2026 Plan")
3. Choose Full Org to copy entire organization
4. Add description: planning scope, assumptions, major initiatives
5. Click Create

### Model All Changes (1.5-2 hours)

**Add new positions (45-60 minutes):**
1. Navigate to each department
2. Add new positions with:
   - Hire dates spread throughout quarter (realistic timeline)
   - Salaries from rate cards
   - Manager assignments
3. Include phased hiring (don't cluster all hires in Month 1)

**Model attrition (30 minutes):**
1. Close positions for expected turnover
2. Use historical attrition rates by department
3. Set termination dates if known
4. Add backfill positions with hire dates

**Model reorganizations (15-30 minutes):**
1. Add any new management positions
2. Move existing positions to new reporting relationships
3. Close redundant positions
4. Set effective dates for phased transitions

### Budget & Forecast Analysis (30 minutes)

1. Open OpEx Panel to check:
   - Net headcount change
   - Net cost change
   - Alignment with quarterly budget
2. Switch to Forecast view:
   - View in Quarterly mode
   - Check month-by-month ramp
   - Verify cost trajectory
3. Export forecast data for stakeholder meetings

---

## Month 1-2 of Quarter: Approval & Implementation

**Estimated time: 1-2 hours**

Get approval and begin implementation.

### Stakeholder Review (30-60 minutes)

1. Share scenario with department leaders for validation
2. Review with Finance to confirm budget alignment
3. Present to leadership if significant changes
4. Make adjustments based on feedback

### Scenario Submission (15 minutes)

1. Update scenario description with any final changes
2. Submit scenario for approval via OpEx Panel
3. Track approval status (Level 0/1/2/3)
4. If rejected: Review feedback, make changes, resubmit

### Implementation Kickoff (15-30 minutes)

Once approved:
1. Communicate plan to relevant stakeholders
2. Share hiring plans with recruiting team
3. Notify managers of approved changes
4. Set up tracking for progress monitoring

---

## Throughout Quarter: Monitoring

**Estimated time: 30 minutes per week**

Track progress and adjust as needed.

### Weekly Check-ins (15 minutes)

1. Track hiring progress vs. plan:
   - Offers extended
   - Start dates scheduled
   - Delays or challenges
2. Track attrition vs. expectations:
   - Resignations
   - Terminations
   - Unplanned departures

### Monthly Review (30 minutes)

1. Update forecast if significant changes occur
2. Create new scenario version if needed:
   - "[Quarter] [Year] Plan v2"
   - Document what changed and why
3. Report actuals vs. plan to Finance and leadership

### Course Corrections (as needed)

If you're significantly off plan:
1. Create a revised scenario
2. Adjust hire dates for delayed positions
3. Add or remove positions based on new priorities
4. Resubmit for approval if budget impact is significant

## Tips for Quarterly Planning

### Best Practices

- **Start early:** Begin gathering inputs in Month 3 of prior quarter
- **Be realistic:** Use achievable hire dates based on recruiting timelines
- **Model attrition:** Always include expected turnover
- **Stagger hires:** Spread hiring throughout the quarter
- **Track progress:** Monitor weekly, report monthly
- **Stay flexible:** Be ready to adjust mid-quarter if needed

### Common Mistakes to Avoid

- Clustering all hires on the first day of the quarter (unrealistic)
- Forgetting to model attrition (creates overly optimistic forecasts)
- Not starting recruiting early enough (leads to end-of-quarter hiring rush)
- Ignoring budget changes mid-quarter (can cause overspend)
- Not versioning scenarios (makes it hard to track changes)

### Integration with Annual Planning

Quarterly planning should roll up to annual plan:
- Q1-Q4 plans should align with FY plan
- Adjust quarterly plans if annual plan changes
- Use quarterly actuals to inform next year's annual plan
- Track cumulative variance across quarters

## Role-Specific Quarterly Planning

Different roles have different focuses:

### For Department Leaders
- Submit your team's hiring plans early (Month 3 of prior quarter)
- Be specific about hire dates and salary levels
- Flag any reorgs or structure changes
- See [Department Lead Checklist](department-lead-checklist.md)

### For Workforce Planners
- Consolidate all department inputs
- Create enterprise-wide quarterly scenario
- Ensure budget alignment
- Report to Finance and leadership
- See [Workforce Planner Checklist](workforce-planner-checklist.md)

### For Admins
- Schedule regular data refreshes (bi-weekly or monthly)
- Process scenario approvals
- Maintain access controls
- Support users with questions
- See [Admin Checklist](admin-checklist.md)
