# Scenario Taskbar

The taskbar in scenarios provides quick access to editing tools, analysis features, and collaboration functions. Unlike Main Org (which is view-only), the Scenario taskbar includes powerful editing capabilities alongside the viewing tools.


> **[Screenshot placeholder: Scenario taskbar showing all available tools and actions]**
## Scenario Taskbar Overview

The taskbar is your command center when working in scenarios. It includes all the viewing tools from Main Org, plus additional actions for making changes, tracking impact, and collaborating with teammates.

**Key difference from Main Org:**
- **Main Org taskbar:** View-only tools (search, filter, analyze)
- **Scenario taskbar:** View tools PLUS edit actions (add, change, approve, share)

---

## View & Navigation Tools

These tools work the same in both Main Org and Scenarios.

### 1. Search

**Icon:** 🔍 Magnifying glass

**What it does:** Find employees or positions by name or job title.

**How to use:**
1. Click the search icon
2. Type a name or title
3. Select from results to navigate to that position

**Keyboard shortcut:** Cmd/Ctrl + K

---

### 2. Filter

**Icon:** Funnel symbol

**What it does:** Show only positions matching specific criteria.

**How to use:**
1. Click the filter icon
2. Select attribute (Department, Location, Pay Grade, etc.)
3. Choose values to include
4. Toggle **Manager Filtering** to preserve hierarchy
5. Click **Apply**

**Important:** Manager Filtering is recommended to keep org structure intact.

**When to use in scenarios:**
- Focus on specific department while editing
- Review all new positions (filter by "newly added")
- Check all RIF'd positions (filter by closure status)

---

### 3. Tree View

**Icon:** List with indentation

**What it does:** Display org structure as a hierarchical list.

**How to use:**
1. Click the tree view icon
2. Browse the indented list
3. Click names to navigate in the org chart

**When to use:** Quickly browse deep hierarchies without expanding cards.

---

### 4. Highlight

**Icon:** Paint palette or color symbol

**What it does:** Color-code cards by any attribute.

**How to use:**
1. Click the highlight icon
2. Select attribute (Department, Work City, Pay Grade, etc.)
3. Cards color automatically
4. Toggle fill color vs outline color
5. Show legend to see color meanings

**Scenario-specific use:**
- Highlight "Change Type" to see adds (green), closures (red), edits (blue)
- Highlight "Department" to verify changes are in right areas
- Highlight two attributes at once (fill + outline)

**Pro tip:** Use "Change Type" highlighting to visually scan all your scenario modifications.

---

### 5. Card Content (Display Settings)

**Icon:** Gear or settings symbol

**What it does:** Control what fields appear on each card.

**How to use:**
1. Click the card content icon
2. Check/uncheck fields to show/hide
3. Drag to reorder fields
4. Changes apply immediately

**Available fields:**
- Standard fields (Name, Title, Department, Salary)
- Custom fields configured by your admin
- Calculated "FX" fields (SOC, Total Org Size, Layer)
- Change indicators (Effective Date, Change Type in scenarios)

**Scenario tip:** Show "Effective Date" field to see when each change takes effect.

---

### 6. Spotlight

**Icon:** Spotlight/flashlight symbol

**What it does:** Dim all positions except selected ones to focus attention.

**How to use:**
1. Select one or more positions
2. Click spotlight icon
3. Selected positions highlighted, all others dimmed
4. Click again to turn off

**When to use in scenarios:**
- Present specific changes to stakeholders
- Focus discussion on key positions
- Review specific team during scenario review

## Scenario-Specific Actions

These actions are **only available in Scenarios**, not in Main Org.

### 7. Change Tracker

**Icon:** 👀 Eye icon or list icon

**What it does:** Opens the Change Tracker panel showing all scenario modifications and cost/headcount impact.

**How to use:**
1. Click the Change Tracker icon (usually visible by default)
2. Panel opens on right side
3. See all additions, reductions, modifications
4. Review net impact at bottom

**When to use:**
- After making any change (check impact immediately)
- Before sharing scenario (verify all changes)
- Before submitting for approval (final review)

**Learn more:** [Scenario Tracking & Analysis](tracking-analysis.md)

---

### 8. Comments

**Icon:** 💬 Speech bubble

**What it does:** Opens the comments panel to view and add scenario discussions.

**How to use:**
1. Click the comments icon
2. Panel opens showing all comments
3. Add new comment or reply to existing
4. @mention teammates to notify them

**When to use:**
- Get feedback on specific changes
- Document decision rationale
- Discuss scenario with collaborators
- Track conversation history

**Learn more:** [Scenario Collaboration](collaboration.md)

---

### 9. Share

**Icon:** 🔗 Share/link symbol

**What it does:** Share the scenario with teammates and control access levels.

**How to use:**
1. Click share icon
2. Enter email addresses or select users
3. Choose access level (View, Edit, or Comment Only)
4. Add optional message
5. Click **Share**

**Access levels:**
- **View Only** - See scenario, cannot edit or comment
- **Edit** - Full editing capability
- **Comment Only** - Can leave feedback but not edit positions

**Learn more:** [Scenario Collaboration](collaboration.md)

---

### 10. Compare

**Icon:** Side-by-side comparison symbol

**What it does:** Opens comparison view to see this scenario alongside others or Main Org.

**How to use:**
1. Click compare icon
2. Select additional scenarios to compare (up to 4 total)
3. Choose comparison mode (Cost, Headcount, Structure, Pyramid)
4. Analyze differences

**When to use:**
- Evaluate multiple scenario options
- Present alternatives to leadership
- Choose best approach from several options

**Learn more:** [Scenario Comparisons](comparisons.md)

---

### 11. Export/Download

**Icon:** ⬇️ Download arrow

**What it does:** Export scenario data in various formats.

**How to use:**
1. Click export icon
2. Choose what to export:
   - **Org Chart** (PDF/PNG)
   - **Change Log** (CSV)
   - **Comparison** (CSV)
   - **Directory** (Excel/CSV)
3. Select format
4. Click **Export**

**What gets exported:**
- Org chart visual with or without change symbols
- Change Tracker data (all modifications)
- Before-and-after comparison data
- Full position details

**When to use:**
- Creating presentations for stakeholders
- Offline analysis in Excel
- Archiving scenario decisions
- Sharing with people outside Agentnoon

**Learn more:** [Exporting & Reporting](../directory/exporting-reporting.md)

---

### 12. Approvals (Submit for Approval)

**Icon:** ✓ Checkmark or approval symbol

**What it does:** Submit scenario through approval workflow for stakeholder sign-off.

**How to use:**
1. Click approvals icon
2. Select approval workflow (if multiple configured)
3. Add message for approvers
4. Click **Submit**
5. Track approval status

**What happens:**
- Scenario sent to configured approvers
- You receive notifications as it's reviewed
- Approvers can approve, reject, or request changes
- Once approved, scenario can be implemented

**When to use:**
- Scenario planning complete and ready for review
- Need formal sign-off before implementation
- Required by organizational process

**Learn more:** [Scenario Approvals](approvals.md)

---

### 13. Workforce Hub

**Icon:** Chart/analytics symbol

**What it does:** Opens analytical dashboards with before-and-after views of key metrics.

**How to use:**
1. Click Workforce Hub icon (or Org Chart dropdown → Workforce Hub)
2. View charts comparing Main Org (before) vs Scenario (after)
3. Analyze metrics:
   - Headcount by dimension
   - Cost by dimension
   - Span of Control
   - Layers
   - Diversity metrics
   - Custom metrics

**When to use:**
- Deep-dive into scenario impact
- Verify reorganization didn't create span issues
- Analyze cost distribution changes
- Present data-driven insights to stakeholders

**Learn more:** [Scenario Tracking & Analysis](tracking-analysis.md)

---

### 14. Directory

**Icon:** Grid or table symbol

**What it does:** Opens spreadsheet-style view of all positions in scenario.

**How to use:**
1. Click directory icon
2. See table of all positions
3. Sort, filter, search
4. Select multiple for bulk actions
5. Export directory data

**When to use:**
- Select many positions for bulk editing
- Review all positions in list format
- Find positions by attributes (filter)
- Export position data

**Learn more:** [Scenario Directory](directory.md)

---

### 15. Timeline (Time-Based Planning)

**Icon:** 📅 Calendar or timeline symbol

**What it does:** View scenario changes across time based on effective dates.

**How to use:**
1. Click timeline icon
2. See changes plotted by effective date
3. View by quarter, month, or custom range
4. See when costs hit
5. Adjust effective dates for positions

**When to use:**
- Phased hiring plans (Q1, Q2, Q3, Q4)
- Schedule reorganization timing
- Track when budget impact occurs
- Present timeline to finance team

**Learn more:** [Time-Based Planning](time-based-planning.md)

## Taskbar Layout

Typical taskbar layout in scenarios (left to right):

**Left side (View & Navigation):**
- Search
- Filter
- Tree View
- Highlight
- Card Content
- Spotlight

**Center:**
- Org Chart / Directory / Workforce Hub selector

**Right side (Scenario Actions):**
- Change Tracker
- Comments
- Share
- Compare
- Export
- Approvals
- Timeline

**Note:** Exact layout may vary by admin configuration and screen size.

## Keyboard Shortcuts

Speed up taskbar actions with shortcuts:

- **Cmd/Ctrl + K** - Search
- **Cmd/Ctrl + F** - Filter
- **Cmd/Ctrl + H** - Highlight
- **Cmd/Ctrl + /** - Comments
- **Cmd/Ctrl + E** - Export
- **Cmd/Ctrl + T** - Tree View
- **Cmd/Ctrl + Click** - Multi-select positions

## Taskbar Tips & Best Practices

1. **Keep Change Tracker visible** - Constant awareness of impact
2. **Use filters to focus** - Work on one department at a time
3. **Highlight change types** - Quickly see all adds/closes/edits
4. **Comment as you go** - Document rationale immediately
5. **Export regularly** - Backup your work
6. **Use spotlight for presentations** - Focus stakeholder attention
7. **Check Workforce Hub** - Deep metrics before finalizing
8. **Submit for approval when ready** - Don't wait until perfect

## Troubleshooting

**Problem:** Can't see Change Tracker icon.
- **Solution:** Click 👀 eye icon to toggle visibility. Or check taskbar settings.

**Problem:** Export button grayed out.
- **Solution:** Check permissions. Export may be restricted by admin.

**Problem:** Approvals button not showing.
- **Solution:** Approval workflows may not be configured. Contact admin.

**Problem:** Timeline button missing.
- **Solution:** Feature may not be enabled. Or no effective dates set on positions.

**Problem:** Directory shows positions I can't see in org chart.
- **Solution:** Check filters in org chart. Directory shows all, org chart may be filtered.
