# Agentnoon Training Deck — Slide Content

This directory contains the slide-by-slide content for the Agentnoon Training Deck. Each subdirectory represents a section of the deck, and each `.md` file represents one slide.

## How to Use These Files

Each slide file follows the same format:

- **Title** — The slide headline
- **Lead-line** — One sentence summarizing the slide's message
- **Key Details** — Bulleted content for the left side of the slide (3–5 bullets)
- **Screenshot** — Description of what screenshot/visual goes on the right side
- **Speaker Notes** — Additional context for anyone presenting this deck live

## Tone & Style

- **Instructional but approachable** — Second person ("you"), active voice
- **No jargon without definition** — Every term is explained on first use
- **Progressive disclosure** — Core slides (1–50) teach in order of need; appendix provides depth on demand
- **Concise** — 3–5 bullets per slide, no walls of text
