# Slide 19 — Spotlight & Saved Views

## Title
Spotlight & Saved Views

## Lead-line
Spotlight highlights positions matching specific rules; Saved Views let you bookmark useful configurations for quick access later.

## Key Details
- **Spotlight:** Click **Spotlight** in the toolbar → choose from pre-configured rules (e.g., "SOC > 15," "Pay Grade = Senior," specific field values). Matching positions stay bright; everything else dims. A list of matching positions appears for quick review.
- **Saved Views:** After you've configured your filters, highlights, and card content the way you want, click **Views** → **Save Current View**. Name it clearly (e.g., "Engineering Team," "US Employees," "SOC Analysis").
- **Reuse views:** Your saved views appear in the Views dropdown for one-click access later. This saves time when you run the same analysis repeatedly.
- **Practical combo:** Set up Card Content with SOC and Layer → apply Spotlight for SOC < 3 → save as "Compression Analysis" view. Next time, one click gets you back to this exact setup.

## Speaker Notes
Spotlight is like a search that works visually across the entire org chart. Instead of filtering positions out, it dims the ones that don't match — so you keep the full context while focusing on what matters. It's particularly useful for things like "show me all managers with fewer than 3 direct reports" or "highlight all positions in a specific pay grade." Saved Views are a huge time-saver. If you run a weekly analysis with the same filters and card content, save it once and you'll never have to set it up again.
