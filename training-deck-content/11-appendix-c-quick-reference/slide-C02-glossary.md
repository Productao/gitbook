# Slide C2 — Glossary of Key Terms

## Title
Glossary

## Lead-line
Quick-reference definitions for the most important Agentnoon terms.

## Key Details

| Term | Definition |
|---|---|
| **Position** | A job role in the org structure — filled or vacant. The core building block of Agentnoon. |
| **Main Org** | Your current-state, view-only organization synced from your HRIS or data import. |
| **Scenario** | An editable copy of your org used for modeling future changes without affecting live data. |
| **OpEx Panel** | The real-time dashboard that tracks every change in a scenario with cost and headcount impact. |
| **Span of Control (SOC)** | The number of direct reports for a given position. Healthy range: 5–10. |
| **Layer** | The number of management levels between a position and the CEO. |
| **RIF** | Reduction in Force — an involuntary position elimination (layoff). |
| **Exit** | A voluntary departure where the position is not backfilled. |
| **FX Field** | A field auto-calculated by Agentnoon (SOC, Layer, Total Org Size, etc.). |
| **Access Group** | A permission set that controls which fields a user can view, edit, or not see. |
| **Scope** | The subset of records (positions/people) a user can see — scoped by manager, department, etc. |
| **Rate Card** | A compensation band lookup table that auto-populates salaries based on role attributes. |
| **Bench** | A holding area for employees detached from positions during restructuring. |
| **Effective Date** | The date when a scenario change takes effect — controls phasing in Forecast. |
| **Forecast** | The time-phased projection view showing headcount and cost over months, quarters, or years. |
| **Workforce Hub** | Agentnoon's analytics module with pre-built charts for structural analysis. |
| **Directory** | The table/spreadsheet view of positions and employees. |
| **Slide Pack** | A multi-chart presentation built from Workforce Hub charts, exportable as PowerPoint. |
