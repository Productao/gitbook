# Slide C1 — Keyboard Shortcuts

## Title
Keyboard Shortcuts

## Lead-line
Navigate faster with keyboard shortcuts — essential commands for power users.

## Key Details

### Module Navigation
| Shortcut | Action |
|---|---|
| **1** | Jump to Org Chart |
| **2** | Jump to Directory |
| **3** | Jump to Forecast |
| **4** | Jump to Workforce Hub |
| **5** | Jump to Activity Analysis |

### Search & Navigation
| Shortcut | Action |
|---|---|
| **Cmd/Ctrl + K** | Open search |
| **/** | Open search (alternative) |
| **Esc** | Close current panel / deselect |

### Directory View
| Shortcut | Action |
|---|---|
| **x** | Select/deselect current row |
| **j** | Move to next row |
| **k** | Move to previous row |
| **p** | Open profile/detail panel |
| **o** | Jump to position in org chart |

### Scenario Org Chart
| Shortcut | Action |
|---|---|
| **x** | Select/deselect current card |

### Tips
- **Cmd** on Mac, **Ctrl** on Windows/Linux
- Module shortcuts (1–5) work from anywhere in the platform
- Combine shortcuts with filters for rapid navigation

## Speaker Notes
You don't need to memorize all of these on day one. Start with three: 1 for Org Chart, 2 for Directory, and Cmd+K for Search. Those three will cover 80% of your navigation. As you get more comfortable, the Directory shortcuts (j/k for row navigation, x for selection, o to jump to org chart) become second nature and dramatically speed up your workflow.
