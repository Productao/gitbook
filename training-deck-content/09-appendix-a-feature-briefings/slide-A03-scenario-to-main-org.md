# Slide A3 — Scenario to Main Org

## Title
Scenario to Main Org

## Lead-line
Apply an approved scenario's changes directly to Main Org — making your plan the new reality.

## What Is It?
Scenario to Main Org is an admin-only operation that merges an approved scenario's changes into the live Main Org. This is used when you want Agentnoon's Main Org to reflect the planned state immediately, rather than waiting for an HRIS data refresh.

## How to Set It Up
- The scenario must be **fully approved** through all required approval levels
- Only **Admins** can perform this operation
- This action is **permanent** — it cannot be undone

## How to Use It
1. Navigate to **Main Org**
2. Go to **Data Management** → **Merge Approved Scenarios**
3. Select the approved scenario
4. Choose which **fields** to bring over
5. Check **"Include New Positions"** if you want newly created positions added to Main Org
6. Review any **conflicts** between scenario data and current Main Org data
7. Click **Merge**
8. **Post-merge:** Verify changes in Main Org → notify stakeholders → archive the scenario

## Important Notes
- Always verify the scenario is fully reviewed before merging
- Communicate the merge to all users who will see the Main Org changes
- Archive the scenario after merging for historical reference

## Speaker Notes
This is the "make it official" step. Most organizations implement changes in their HRIS first and then let the data refresh update Main Org. But Scenario to Main Org is useful when you want to update Agentnoon's baseline immediately — for example, if you've approved a reorg and want to start planning the next phase from the new structure without waiting for the HRIS sync. Because it's permanent, always double-check everything before merging.
