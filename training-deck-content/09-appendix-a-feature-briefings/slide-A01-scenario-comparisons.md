# Slide A1 — Scenario Comparisons (Deep Dive)

## Title
Scenario Comparisons

## Lead-line
Compare two scenarios side-by-side to make data-driven decisions between competing approaches.

## What Is It?
Scenario Comparisons let you put two scenarios next to each other and compare them across multiple dimensions: cost, headcount, org structure, and structural metrics. You can also compare a scenario against Main Org to see proposed vs. current state.

## How to Set It Up
1. Create two or more scenarios representing different approaches (e.g., "Conservative Hiring Plan" and "Aggressive Hiring Plan")
2. Build out each scenario with its respective changes
3. Review each scenario individually before comparing

## How to Use It
1. Go to the **Homepage**
2. Select exactly **two scenarios** (or one scenario + Main Org)
3. Click **Compare**
4. Review side-by-side: **Cost** (total and delta), **Headcount** (total and delta), **Org Chart** (structural differences), **Pyramid Chart** (shape comparison), **Key Metrics** (SOC, layers, ratios)
5. **Export** as Excel (multi-sheet), CSV, or PowerPoint for stakeholder presentations

## Speaker Notes
Comparisons are most valuable when you're presenting options to leadership. Instead of one plan, present two with clear trade-offs. The Excel export is particularly useful for Finance — it gives them everything in a familiar format with multiple tabs for different comparison dimensions.
