# Slide A4 — Time-Based Planning (Deep Dive)

## Title
Time-Based Planning

## Lead-line
Phase your changes over time with three date types — hire dates, termination dates, and effective dates.

## What Is It?
Time-Based Planning uses dates on scenario changes to control when each change takes effect. This turns a static "before and after" into a dynamic, phased plan that unfolds over months and quarters in the Forecast view.

## How to Set It Up
When making any change in a scenario, look for the date field in the edit panel and assign the appropriate date:
- **Hire Date** — For new positions (when the position becomes active/filled)
- **Termination Date** — For closed positions (when the position is eliminated)
- **Effective Date** — For modifications like moves, title changes, or salary adjustments (when the change takes effect)

## How to Use It
1. **Create your scenario** and make changes as usual
2. **Assign dates** to each change:
   - New engineering hire starting April 1 → set Hire Date: 2026-04-01
   - Marketing role closing end of Q1 → set Termination Date: 2026-03-31
   - Team moving to new department July 1 → set Effective Date: 2026-07-01
3. **View in Forecast** → switch to Quarterly or Monthly to see changes phase in over time
4. **Review in OpEx Panel** → use Effective Date view to see changes grouped by period
5. **Forecast extends 5 years** from today for long-range planning

## Example: Phased Hiring Plan
- Q1: 5 engineers (Hire Date: Jan–Mar)
- Q2: 3 engineers (Hire Date: Apr–Jun)
- Q3: 2 engineers (Hire Date: Jul–Sep)
- Forecast shows headcount stepping up: 105 → 110 → 113 → 115 across quarters

## Speaker Notes
Time-Based Planning is the difference between "we're adding 10 people" and "we're adding 3 in Q1, 4 in Q2, and 3 in Q3 — here's the quarterly cost impact." Always set dates. Without them, Forecast assumes everything happens immediately, which gives an inaccurate picture. A realistic phased plan is also more credible to approvers and Finance partners.
