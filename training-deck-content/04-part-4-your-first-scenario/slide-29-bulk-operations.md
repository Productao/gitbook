# Slide 29 — Bulk Operations

## Title
Bulk Operations

## Lead-line
Select multiple positions at once and apply changes in batch — essential for reorganizations at scale.

## Key Details
- **Three ways to select multiple positions:**
  - **Org chart:** Hold **Cmd/Ctrl** and click individual cards one at a time
  - **Select Team:** Right-click a manager → **"Select Team"** to select all their direct and indirect reports
  - **Directory:** Switch to Directory view → use checkboxes to select rows (use the header checkbox to select all filtered rows)
- **Available bulk actions:** Edit Attributes (change department, location, pay grade, etc. for all selected), Change Manager (move all selected to a new manager), Close Positions (RIF multiple roles), Detach Employees, Duplicate positions
- **Example workflow:** Filter to a department → select all positions → bulk edit Department field to the new department name → Save. Dozens of changes in seconds.
- **Tracking:** Every individual change within a bulk operation is tracked separately in the OpEx Panel

## Speaker Notes
Bulk operations are where you go from "I can do this in Agentnoon" to "I can do this faster in Agentnoon than any other way." If you're reorganizing a team of 50 people and need to change everyone's department, you don't have to click each card individually. Select the whole team, bulk edit the department field, done. The Directory view is especially powerful for bulk selection — you can filter down to exactly the positions you need, check the "select all" box, and apply changes. One tip: always use "Show Changes" after a bulk operation to verify that everything changed as expected before moving on.
