# Scenario Refresh

### Overview

This guide explains how to refresh scenarios in Agentnoon when your main org chart is updated, ensuring your scenario data stays current while preserving key modifications.

#### **1.** Update Your Main Org Chart

1. If your org chart is connected to a Google Sheet, sync the latest data.
2. If using a CSV file, re-upload the updated file.
3. The changes will now reflect in your main org chart, but not in existing scenarios.

#### **2.** Refresh the Scenario

1. Open your scenario and go to **Data Management > Refresh Scenario**.

<figure><img src="../.gitbook/assets/Screenshot 2025-11-11 at 6.21.59 PM.png" alt="" width="375"><figcaption></figcaption></figure>

2. Select the scenario to refresh and rename it (e.g., "Copy" to retain the original version).
3. Click **Next** to compare and resolve data conflicts.

<figure><img src="../.gitbook/assets/Screenshot 2025-03-26 at 4.27.46 PM (1).png" alt=""><figcaption></figcaption></figure>

#### 3. Resolve Conflicts & Apply Updates

1. **For manually modified positions**, choose whether to keep scenario-specific changes or revert to the main org data.
2. **For unchanged positions**, updates from the main org chart will apply automatically.
3. Use **Select All** to quickly apply multiple changes.
4. Click **Next** to finalize the refresh.

<figure><img src="../.gitbook/assets/Screenshot 2025-03-26 at 4.28.09 PM (1).png" alt=""><figcaption></figcaption></figure>

#### Results After Refresh

1. Scenario retains manual changes you chose to keep.
2. Unchanged positions update automatically from the main org chart.
3. Scenario remains in sync with the latest organizational data.

Refreshing scenarios helps maintain data accuracy while preserving key planning decisions.&#x20;
