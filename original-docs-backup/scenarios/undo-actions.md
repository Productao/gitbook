# Undo Actions

### Overview

This guide explains how to use the Undo feature in Agentnoon to revert recent changes in a scenario. The Undo function allows users to quickly correct actions and navigate changes with more flexibility.

#### 1. Navigate to the Activity Log

* Open a **scenario** in Agentnoon.
* Click **Activity** in the vertical navigation bar at the bottom left.
* View the list of **recent actions** performed in the scenario.

<div align="left"><figure><img src="../.gitbook/assets/Screenshot 2025-03-06 at 3.28.55 PM.png" alt="" width="375"><figcaption></figcaption></figure></div>

#### 2. Undoing an Action

* Locate the action you want to revert in the **Activity Log**.
* Hover over the action to reveal the **Undo** option.
* Click **Undo** to revert the change instantly.

The Undo feature helps making adjustments to a scenario, ensuring smooth scenario planning in Agentnoon.
