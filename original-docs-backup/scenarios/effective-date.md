# Effective Date

### When to Use Effective Date

Effective dates are ideal when planning changes that should not apply immediately, such as:

* Promotions
* Role or title changes
* Compensation or salary updates
* Terminations or exits

Using an effective date ensures that future or past changes are reflected correctly in scenarios and exports.

### How Effective Date Works

When making a change in the application, users can assign an effective date to specify **when** the update should apply.

* The change is stored in the system with its effective date

This allows teams to plan ahead while preserving data accuracy.

### Making Changes with an Effective Date

To apply an effective date:

1. Make the desired change (e.g., role, compensation, or status update).
2. Select an effective date for the change (look for the "Effective date" field on the top of the edit panel).
3. Save the update.

The system records the change and applies it based on the selected date.
