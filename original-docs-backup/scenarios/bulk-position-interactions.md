# Bulk Position Interactions

### Overview

This guide explains how to perform bulk edits in Agentnoon, allowing you to efficiently update multiple positions, mark reductions, reassign managers, and make other large-scale changes.

### Ways to Select Multiple Positions

#### 1. Org Chart Keyboard Shortcuts

1. Use **Command + click** (Mac) or **Control + K** (Windows) to select multiple positions.
2. You can also hover over an org chart card and click `x` key to select multiple positions.
3. This opens the **bulk edit panel**, where you can modify attributes for all selected positions at once.

#### 2. Selecting a Whole Team

1. Click the **three-dot menu** on a position card.
2. Choose **Select Team** to automatically select a position and all its direct reports.
3. This makes it easy to apply bulk edits to an entire hierarchy.

<div align="left"><figure><img src="../.gitbook/assets/Screenshot 2025-11-11 at 6.19.06 PM.png" alt="" width="563"><figcaption></figcaption></figure></div>

#### 3. Using the Directory View

1. Open the **Directory** for a **spreadsheet-style list** of all positions.
2. Apply **filters** to narrow down selections (e.g., selecting all positions in a specific department).
3. Click the **checkbox at the top** to select all filtered positions for bulk editing.

### Bulk Edit Actions

When you select more than one position - either in the Org Chart or Directory - the **bulk edit sidebar** opens automatically, allowing you to make changes across all selected roles at once.

#### 1. Edit Attributes&#x20;

* Modify fields like **Department, Job Title, or Location** for multiple positions at once.
* Example: Assign **Marketing** as the department for all selected positions.

#### 2. Remove Employees

1. **RIF** : Bulk mark positions as **reductions (layoffs)**
2. **Exit** : Bulk mark positions as **exits (voluntary departures)**.
3. **Detach** : Bulk detach employees from positions.

#### 3. Change Manager Assignments

1. Select multiple positions and use **Change Manager** to reassign them under a new leader.
2. Works for both individual positions and entire teams.

#### 4. Bench Employees

1. Select multiple positions and mark them as **Benched** to indicate roles under consideration.
2.  Useful for roles that are on hold, pending decisions, or earmarked for future planning.\
